# TechBench Inventory Beta 0.5.58-beta.1

This opt-in beta adds the live SQL-backed Inventory Board for TechBench Admins.

- Uses the existing TechBench database at schema 14.
- Adds stock, technician, and deployment lanes with drag-and-drop prioritization.
- Keeps deploying technicians visible in the deployment section.
- Supports resizable and collapsible deployment space.
- Adds equipment details, assignment, client/user linkage, and deployment tracking.
- Uses the isolated `inventory-beta` update channel; stable 0.5.57 users are not notified.

Install this beta only on a workstation selected for Inventory Board testing.
