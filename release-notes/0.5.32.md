# TechBench 0.5.32

- Administrator-triggered WHD synchronization now requests a full organization refresh instead of an incremental ticket-only run.
- The full request refreshes WHD clients, statuses, technicians, technician groups, and tickets, so Server Manager's User Mappings roster is refreshed immediately.
- The Admin Center button is renamed to **Sync all WHD data now** to reflect the operation it queues on the server.
- If WHD returns the authenticated administrator's real `currentTechId` but denies both technician-detail routes, the service retains that authoritative ID with the configured organization username instead of dropping the account.
- This release continues to use SQL Server schema version 11; no SQL update is required when upgrading from 0.5.24 through 0.5.31.
