# TechBench Inventory Beta 0.5.88-beta.1

- Replaces the Stock-only Inventory page with an All Equipment registry covering
  Stock, technician work, and Deployment records.
- Adds equipment search across name, asset tag, serial number, client, client
  user, and technician, plus status, device type, client, technician, and
  Stock-only filters.
- Opens a selected registry row in the editable Inventory tray. Import, new,
  save, and archive actions are now available only from Inventory.
- Keeps Equipment Board focused on its existing technician lanes, card
  drag-and-drop, work priority, and Deployment ordering workflow.
- Keeps equipment details on the current page outside Inventory in a read-only
  tray, with Copy details available from either tray. AnyDesk passwords are
  excluded from bulk copy.
- Adds filtering, view-separation, Board drag-workflow, and independent editor
  XAML load regression coverage.

This is a client-only beta update. It remains compatible with TechBench Server
0.5.81 and database schema 15.
