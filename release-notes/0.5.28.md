# TechBench 0.5.28

This coordinated client, server, and SQL release further hardens Admin Center response rendering and adds durable crash diagnostics.

- Recent client responses no longer use bound WPF inline `Run` elements. User, machine, response, and original-message values are rendered through explicit one-way `TextBlock` bindings.
- Startup, dispatcher, and unobserved task failures are recorded in `%LOCALAPPDATA%\CSRI\TechBench V2\crash.log`.
- A workspace-construction failure now reports the diagnostic-file location in its error dialog.
- No database change is required when upgrading from schema version 11.
