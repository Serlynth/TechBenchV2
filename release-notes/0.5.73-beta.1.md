# TechBench 0.5.73-beta.1

- Fixes Credentials synchronization for `Client Users` worksheets that label the person column `User`.
- Accepts flexible client identity headings: `Client`, `Customer`, `Company`, or `Organization`.
- Accepts flexible person identity headings: `User`, `User / Contact`, `Contact`, `Person`, or `Name`.
- Continues discovering every other named column dynamically, so non-identity columns can be added, removed, renamed, or reordered without a code or SQL schema update.
- Prevents the selected person identity column from being displayed again as a credential field.
- Retains the Inventory Beta equipment-board features while remaining compatible with the live schema 14 database.

Install TechBench Server 0.5.73 for the synchronization fix. The SQL schema remains version 14 and does not need to be reapplied.
