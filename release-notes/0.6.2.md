# TechBench V2 0.6.2

This stable bridge keeps the 0.6.1 behavior and adds an opt-in Client Info Beta
update channel.

- Adds **Use Client Info Beta update channel** under Settings.
- Adds the same selector to the database connection window for recovery and
  first-time setup.
- Keeps the existing FireDrill Client Info pane and all stable 0.6.1 database
  behavior.
- Lets testers return to Stable through the normal updater without manually
  reinstalling TechBench.

Canonical Client Info is enabled only in builds published to the
`client-info-beta` channel.
