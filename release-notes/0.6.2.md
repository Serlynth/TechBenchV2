# TechBench V2 0.6.2

This stable bridge keeps the 0.6.1 behavior and adds an opt-in Client Info Beta
update channel.

- Adds **Use Client Info Beta update channel** under Settings.
- Adds the same selector to the database connection window for recovery and
  first-time setup.
- Keeps the existing FireDrill Client Info pane and all stable 0.6.1 database
  behavior.
- Lets testers return to Stable through the normal updater without manually
  reinstalling TechBench.
- Updates the single production Server Manager and Sync Service line with the
  additive canonical Client Info SQL extension. The same server installation
  supports both Stable and Client Info Beta workstations.
- Keeps Server Manager updates on stable releases only; desktop beta channels
  do not create a separate beta server line.
- Ships the matching idempotent SQLCMD bundle as a separate DBA-controlled
  asset. Server Manager updates do not silently execute database scripts.

Canonical Client Info is enabled only in builds published to the
`client-info-beta` channel.
