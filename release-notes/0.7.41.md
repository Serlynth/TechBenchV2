# TechBench 0.7.41

- Adds an always-visible search box and sortable columns to every Client Information full list, with wider, wrapped columns for the technology sections.
- Keeps selected technology summaries compact instead of stretching a single card across the full window.
- Adds lifecycle filtering and name, status, update-time, or internal-ID sorting to the root Client Information client list.
- Imports new FireDrill WatchGuard fields as one linked Connection & Internet record rather than unrelated password rows.
- Automatically organizes previously imported unlinked FireDrill wireless and WatchGuard entries into the client's Wi-Fi and Connection & Internet records while preserving their encrypted secrets.

This is a client-only Stable update and remains compatible with TechBench Server 0.6.28.
