# TechBench V2 2.0.0-alpha.21

Alpha.21 simplifies work-entry tags into one automatic, personal suggestion control.

- The work-entry editor now has one editable **Tags** dropdown instead of separate **Tags** and **Add saved tag** controls.
- Opening the dropdown shows tags previously used by the effective signed-in user.
- Users can still type a new tag or enter multiple comma-separated tags.
- Saving a work entry refreshes the suggestions immediately.
- The Admin-only **Common Tags** section has been removed from client Settings.
- Tag suggestions are owner-scoped in SQL Server and do not expose another user's work history. Admin read-only preview receives the previewed user's suggestions.

The database remains schema version 7, but the matching alpha.21 SQL deployment must be run once to refresh `tb_app.GetDistinctTags`. Existing work entries, tags, and all other data are preserved.
