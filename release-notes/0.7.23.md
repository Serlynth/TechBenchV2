# TechBench 0.7.23

- Adds the primary username and password directly to each application, security product, server, service, and other Client Information record while retaining a Passwords tab for additional logins.
- Gives Connection & Internet records separate Status and Admin username/password fields for firewalls such as WatchGuard.
- Keeps each credential linked to its owning item so it is shown both with that item and automatically in the master Passwords section without duplicating the stored secret.
- Shows explicit Username and Password rows on selected application and security cards, including Microsoft 365 and ESET.
- Updates the Client Information migration workbook to TB-CI-10, placing login fields beside every supported resource and separate Status/Admin login columns beside firewall records.
- Imports application, security, firewall, and other resource credentials into the same linked records used by the master Passwords section while continuing to accept older workbook versions.

This is a client-only update. No SQL, Server Manager, or Sync Service update is required.
