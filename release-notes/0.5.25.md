# TechBench 0.5.25

## Admin Center refresh correction

- Corrects the read-only activity-label binding that caused Admin Center refreshes to stop with a WPF binding error.
- Renames the button to **Refresh all** and makes it update WHD status, Sage status, active clients, and recent client responses together.
- Both synchronization cards now display the last server attempt as well as the last successful run, making a queued request distinguishable from a completed synchronization.
- The Admin Center continues to refresh these same sections automatically every 15 seconds while it is open.

This release continues to use SQL schema version 11. No SQL change is required from TechBench 0.5.24.
