# TechBench Inventory Beta 0.5.67-beta.1

- Selecting a live equipment card or adding a device now opens the details editor automatically, matching Demo Mode.
- Technician headers have a visible drag cue and can be dragged left or right; the arrow controls remain available as a fallback.
- Individual technician columns can be hidden locally from either work or Deployment, with one button to restore all hidden technicians.
- On first launch after this update, the signed-in technician is placed immediately after Stock Room. Later manual rearranging remains saved on that workstation.

No SQL schema or server update is required for this release.
