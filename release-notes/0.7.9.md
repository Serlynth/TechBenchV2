# TechBench V2 0.7.9

## WHD image attachments

- Fixes WHD image uploads that failed with `Required request part 'file' is not present` even though the note itself posted successfully.
- Uses the multipart field name required by current WHD versions.
- Retains a safe compatibility fallback for older WHD versions without risking duplicate uploads after an uncertain server response.
- Keeps selected images attached to the normal **Post/Update WHD** action; images are not stored in TechBench or SQL.

## Deployment

- This is a Stable client-only update. No TechBench Server or SQL update is required.
