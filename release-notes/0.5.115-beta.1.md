# TechBench V2 0.5.115-beta.1

- Makes the canonical **TechBench client name** editable from Client Match.
- Keeps WHD-to-Sage matching as the first step and suggests the current matched
  Sage customer name when the canonical name is stale.
- Lets an Admin accept the suggestion or enter a different organization name.
- Preserves the existing WHD location, Sage customer, tickets, notes, and other
  linked records when the TechBench client name is changed.
- Adds regression coverage for the Teeters Harvey / Marrone & O'Rourke rename
  scenario.

This is a **client-only beta update**. No server, SQL, or sync-service update is
required.
