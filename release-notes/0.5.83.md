# TechBench V2 0.5.83

- Full Web Help Desk ticket refreshes now have five minutes per required API request instead of 90 seconds, preventing slower WHD ticket pages from being reported as a generic cancellation.
- Optional per-client detail enrichment is limited to 20 seconds and falls back to the client list data, so a slow legacy client record cannot cancel the complete location snapshot.
- WHD request timeouts now identify the affected ticket or client-list operation instead of displaying only `The operation was canceled`.
- This stable hotfix contains no beta UI changes.
- No SQL deployment is required. Database schema remains version 15.
