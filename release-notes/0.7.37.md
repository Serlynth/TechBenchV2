# TechBench 0.7.37

- Turns the selected Client Information user area into a clear profile card with initials, status, contact details, Active Directory access, Microsoft 365/Azure Sync details, and workstation name.
- Shows compact Inventory-backed device cards for the selected user, including type, model, serial number, asset tag, assignment status, location, and technician.
- Matches assigned devices safely by user email, normalized user name, or PC name without creating a second equipment record.
- Fixes Users row selection so clicking a row immediately updates the summary and assigned-device cards.

This is a client-only Stable update and remains compatible with TechBench Server 0.6.28.
