# TechBench V2 0.6.6-beta.8

- Expands the upper Client Information overview from a short six-field summary
  into a complete operational view of every nonblank standard and custom field.
- Shows provider, location, address or console URL, category-specific technical
  details, imported custom fields, notes, active state, review state, and last
  verification together on the appropriate overview card.
- Shows linked credentials alongside their system or service with username,
  login URL, notes, and masked protected-value counts. Secrets remain protected
  and continue to use the audited Passwords workflow.
- Places standalone FireDrill-style access records into the appropriate
  overview section, including WatchGuard, Wi-Fi, Microsoft 365, Veeam, ESET,
  Barracuda, Active Directory, remote access, ILO, UPS, and similar records.
- Expands Demo Client with complete fictional examples of those common
  FireDrill groups so each section demonstrates the intended layout.

This is a Client Info Beta client-only update. TechBench Server 0.6.13 and the
schema-version-15 SQL deployment remain current; no server or SQL update is
required.
