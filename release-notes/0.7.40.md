# TechBench 0.7.40

- Hides the Active Directory password controls on a user summary when that user does not yet have an AD password stored.
- Makes assigned-equipment cards clickable and opens the shared read-only Equipment Details drawer without leaving Client Information.
- Keeps AnyDesk launching available from the shared equipment drawer when a device has an AnyDesk address.

This is a client-only Stable update and remains compatible with TechBench Server 0.6.28.
