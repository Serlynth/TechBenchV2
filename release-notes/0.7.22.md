# TechBench 0.7.22

- Replaces the free-text Microsoft 365 license field with a fixed dropdown containing the five licenses CSRI sells.
- Keeps incomplete user records blank until a license is deliberately selected instead of silently choosing a default.
- Adds the same five-choice validation list to the Microsoft 365 License column in newly generated Client Information migration workbooks.
- Continues importing older migration workbooks and normalizes their common shortened license names when users are edited.

This is a client-only update. No SQL, Server Manager, or Sync Service update is required.
