# TechBench V2 0.6.8

- Fixes Copy and Cut in work-note editors when invoked with Ctrl+C, Ctrl+X,
  or the standard right-click menu.
- Routes text-box clipboard writes through TechBench's retrying STA clipboard
  worker for better reliability with RDP and clipboard managers.
- Ensures Cut never removes selected text unless the clipboard write succeeds.

This client update does not change TechBench Server or the database.
