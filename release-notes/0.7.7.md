# TechBench V2 0.7.7

## One WHD action

- Consolidates WHD note posting, exact-note updates, reconciliation, and image
  attachments into the single WHD choice under **Post**.
- Sends any selected images with that Post/Update action, including when adding
  images to an existing WHD TechNote whose text has not changed.
- Removes the separate **Send to WHD**, **Sync WHD Note**, and manual posted-state
  controls from the normal editor workflow.
- Makes **Save** local to TechBench; remote WHD changes now happen only through
  the explicit Post/Update action.
- Keeps failed image uploads selected for retry and prevents new image selection
  after the entry has been locked by Sage.

## Deployment

- This is a Stable client-only update. No TechBench Server or SQL update is
  required.
