# TechBench V2 0.6.6-beta.11

- Turns the main Client Information Overview into a technician quick-reference
  dashboard across the fixed WiFi, WatchGuard, Domain & AD, Microsoft 365,
  Remote Access, infrastructure, ILO / iDRAC, UPS, Veeam, ESET, Barracuda, and
  related operational groups.
- Keeps the quick reference intentionally curated and bounded so technicians can
  find common connection, account, addressing, support, and system details
  without reading every record.
- Makes the lower category tables the comprehensive record view: every standard
  category field, every custom field, notes, active state, review state, and
  verification/update timestamps remain visible and editable.
- Expands the People, Locations, Equipment, Passwords, Attachments, and Other
  Information tables with copy support and their additional operational fields.
- Makes synchronized main-contact values and all quick-reference values
  selectable for normal Ctrl+C or right-click copying.
- Corrects future desktop release tagging so new Stable and Client Info Beta
  builds remain discoverable by the in-app updater.

This is a Client Info Beta client-only update. TechBench Server 0.6.13 and
schema version 15 remain current; no server or SQL update is required.
