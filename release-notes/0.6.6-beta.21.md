# TechBench V2 0.6.6-beta.21

- Removes Remote Access from the technician quick-reference area while keeping
  its complete records available in Applications & Cloud.
- Renames the server-management quick-reference card to ILO; legacy iDRAC data
  can still be recognized without appearing as a separate label.
- Reduces the UPS quick-reference card to Location, Model, IP, Username, and
  Password only.

This is a Client Info Beta client-only layout update. TechBench Server 0.6.13
and schema version 15 remain current; no server or SQL update is required.
