# TechBench Inventory Beta 0.5.66-beta.1

- Technician columns on the Equipment Board can be dragged left or right into a preferred order.
- The technician order stays aligned between active work and Deployment and is remembered on that workstation.
- The equipment details panel can be hidden to give the board more room, then shown again when needed.
- The details-panel preference is remembered on that workstation.

No SQL schema or server update is required for this release.
