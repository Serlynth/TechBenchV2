# TechBench V2 0.6.6-beta.23

- Removes the descriptive sentence beneath every Technician Quick Reference
  card title so the cards stay compact and immediately scannable.
- Replaces the aggregated ILO summary with one card per server.
- Limits each ILO card to host name, host IP, username, and password, while
  keeping password reveal and copy inline.
- Matches each ILO card to credentials linked to that server so access details
  are not mixed between hosts.

This is a Client Info Beta client-only layout update. TechBench Server 0.6.13
and schema version 15 remain current; no server or SQL update is required.
