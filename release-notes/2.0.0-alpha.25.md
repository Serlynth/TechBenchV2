# TechBench V2 2.0.0-alpha.25

Alpha.25 fixes AD-to-WHD technician selections resetting when another Server Manager setting was saved.

- The Web Help Desk button is now labeled `Save settings + mappings` and saves the complete mapping grid before refreshing the page.
- `Sync now` also saves pending mapping changes before it queues WHD synchronization.
- Saving Sage configuration preserves any mapping edits already made on the WHD tab.
- The currently open technician dropdown is explicitly committed before mapping values are sent to SQL Server.
- The dedicated `Save all mappings` button remains available for mapping-only changes.

The database remains schema version 7 and this release does not add a database migration.
