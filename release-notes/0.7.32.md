# TechBench 0.7.32

- Makes the TechBench client and its internal ID the permanent master record when linking Web Help Desk and Sage.
- Automatically links confident WHD and Sage matches to an existing Live TechBench client, regardless of which system receives the client first.
- Automatically creates a Live, Unverified TechBench Client Information record when a new WHD client and Sage customer confidently match each other.
- Lets **+ New client** adopt a single exact-name WHD- or Sage-only record instead of creating a duplicate.
- Preserves the TechBench client name, active state, Client Information, equipment, tickets, work entries, and other linked data during reconciliation.
- Keeps ambiguous matches in Client Match for an administrator instead of guessing.
- Reworks Client Match around independent TechBench, WHD, and Sage presence, with the internal TechBench ID and clear TB-only, partially linked, and fully linked statuses.
- Updates the Client Match Excel export with TechBench/WHD/Sage presence and totals.

This Stable client release is paired with TechBench Server 0.6.26. Install the stable server package and apply its schema-15-compatible SQL update before using the new three-way Client Match actions.
