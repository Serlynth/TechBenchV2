# TechBench V2 0.6.6-beta.15

- Reduces the Wi-Fi overview to Type, Management URL, administrator access,
  and every configured SSID with its linked password.
- Reduces the Connection overview to External IP, model, Status and Admin
  passwords, Firebox-DB or CSRIAdmin AuthPoint access, AuthPoint user, SSL VPN,
  WatchGuard Cloud, and WatchGuard AD authentication.
- Keeps passwords protected behind the existing Reveal and Copy actions while
  removing firmware, gateway, subnet, VLAN, circuit, and other secondary
  details from these quick-reference cards. The complete records remain in the
  full lists below.

This is a Client Info Beta client-only update. TechBench Server 0.6.13 and
schema version 15 remain current; no server or SQL update is required.
