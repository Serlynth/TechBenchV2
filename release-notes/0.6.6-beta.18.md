# TechBench V2 0.6.6-beta.18

- Makes the Locations and People panes independently resizable with a visible
  divider and remembers the chosen split on this workstation.
- Restores normal DataGrid column resize handles, readable minimum widths, and
  horizontal scrolling so long names, addresses, roles, email addresses, and
  dates are no longer compressed into unreadable cells.
- Remembers the individual Location and People column widths along with the
  Client Info window size and maximized state.

This is a Client Info Beta client-only layout update. TechBench Server 0.6.13
and schema version 15 remain current; no server or SQL update is required.
