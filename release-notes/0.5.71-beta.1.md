# TechBench Inventory Beta 0.5.71-beta.1

- Adds a **Users** workspace beneath **Clients**.
- Imports the `Client Users` worksheet from the protected Credentials workbook.
- Supports the worksheet's current two-row grouped headers and dynamically accepts future account columns.
- Lets every authorized TechBench user search the appropriate client-user rows while keeping account values masked.
- Decrypts account details only after **Reveal Accounts** is selected and provides non-blocking copy buttons.

Apply the Stable 0.5.71 SQL installer and update TechBench Server to 0.5.71 before installing this Inventory Beta client.
