# TechBench 0.5.33

- Credentials workbook import is now header-driven instead of tied to eleven fixed column positions.
- `Client` remains the single required column. Every other nonblank, uniquely named column is imported as a credential field.
- Newly appended or reordered columns appear automatically in Client Credentials after the next successful server synchronization.
- Each flexible field value is encrypted separately in SQL Server; client result cards continue to expose only the client name.
- Duplicate or blank headers, duplicate clients, invalid rows, and encryption failures leave the previous SQL snapshot unchanged.
- Adds SQL Server schema version 12. Apply the matching SQL deployment before updating the 0.5.33 server or client.
