# TechBench V2 0.6.2-beta.3

This beta makes canonical Client Info a clearly separate workspace instead of
placing it behind the FireDrill client double-click action.

- Adds **CLIENTS > Client Info (Beta)** to the beta navigation.
- Lists active SQL clients directly from `tb_data.Clients`, including the
  internal client ID, canonical record counts, review status, and cutover state.
- Supports searching by client name or internal client ID and opening the
  canonical tabbed editor from an explicit button or row double-click.
- Restores FireDrill double-click to the existing FireDrill client profile, so
  FireDrill remains unchanged and operational during migration.
- Keeps the new workspace hidden in Stable builds. Stable and beta continue to
  use the same database and update-channel switch.

The current Stable 0.6.4 SQL bundle is still required. This client update does
not introduce a new schema change and does not require rerunning SQL if 0.6.4
already completed successfully.
