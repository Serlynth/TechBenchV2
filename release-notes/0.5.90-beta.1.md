# TechBench Inventory Beta 0.5.90-beta.1

- Renames the Worklog navigation group to Notes.
- Removes the separate Service group and places Tickets, Posting Queue, and
  Posting History in Notes.
- Moves Client Matching from Clients to System.
- Keeps the Inventory registry visible when equipment details open in the
  right-side editor drawer instead of allowing the drawer to push the registry
  below the viewport.
- Adds regression coverage for the new navigation hierarchy and the Inventory
  master/detail layout.

This is a client-only beta update. It remains compatible with TechBench Server
0.5.81 and database schema 15.
