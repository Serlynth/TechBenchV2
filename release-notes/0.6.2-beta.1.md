# TechBench V2 0.6.2-beta.1

This isolated beta introduces the canonical Client Info migration workspace.

- Adds normalized SQL Server tables for client profiles, locations, people,
  systems and services, credentials, encrypted secrets, other facts,
  provenance, import review, and per-client cutover state.
- Keeps the shared database at schema version 15 so installed TechBench 0.6.1
  clients and the existing sync service remain compatible.
- Opens the new tabbed Client Info editor from the existing client
  double-click workflow when the optional beta capability is installed.
- Adds row-version conflict handling for simultaneous editors.
- Generates and imports a practical six-tab Excel migration workbook tied to
  the existing internal client ID.
- Stages each client independently, validates it, compares encrypted secret
  values with current FireDrill data, and requires explicit admin approval
  before promotion.
- Uses a separate `client-info-beta` update channel and side-by-side beta
  installer identity. The stable release channel is unchanged.

FireDrill remains operational during this beta. Its final shutdown is a later,
coordinated stable cutover after all clients are migrated and verified.
