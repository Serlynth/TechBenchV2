# TechBench V2 2.0.0-alpha.24

Alpha.24 fixes the Server Manager self-update failure that could leave the compiled Manager executable missing after rollback.

- The elevated update helper now starts from the downloaded package directory instead of inheriting the installed Manager directory as its working directory.
- The updater waits for the old Server Manager process to exit and aborts before changing installed files if it remains open.
- Directory replacement now retries transient Windows file locks before beginning rollback.
- A failed handoff can no longer continue into the installed Manager and service directories after the 30-second shutdown timeout.

The database remains schema version 7. This release does not add a database migration. If alpha.23 left Server Manager damaged, run the alpha.24 `TechBenchServerSetup.exe` directly; it repairs the installation while preserving the service identity, SQL settings, and protected WHD/Sage credentials.
