# TechBench Inventory Beta 0.5.93-beta.1

- Expands equipment details into a full-height side sheet inside the popped-out
  client profile, including the former profile-banner space.
- Widens the details sheet so equipment and assignment fields are easier to
  scan while the client overview remains visible behind it.
- Preserves the existing Close, Back, and Escape behavior.
- Adds regression coverage for the full-window drawer placement and width.

This is a client-only beta update. It remains compatible with TechBench Server
0.5.81 and database schema 15.
