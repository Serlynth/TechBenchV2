# TechBench V2 0.5.84

- **Sync all WHD data now** still refreshes clients, statuses, technicians, groups, and tickets, but the ticket step now resumes from the latest successful ticket cursor when one exists instead of rescanning the entire WHD ticket history.
- The first-ever ticket synchronization still performs a complete historical bootstrap when no cursor exists.
- Admin Center and Server Manager now show an active synchronization as in progress and label any stored error as a previous failure instead of presenting contradictory `Running: ... failed` text.
- This stable hotfix contains no beta UI changes.
- No SQL deployment is required. Database schema remains version 15.
