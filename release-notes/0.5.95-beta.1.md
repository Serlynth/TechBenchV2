# TechBench Inventory Beta 0.5.95-beta.1

- Prevents one legacy Web Help Desk client record with an invalid provider
  email from stopping the complete client synchronization.
- When WHD rejects an optional individual client-detail request with HTTP 400,
  the Sync Service now retains the usable contact data from the client list and
  completes the location snapshot.
- Reports the rejected WHD client ID in the successful sync summary so the
  source record can still be corrected.
- Continues to fail the sync for authentication errors, timeouts, and WHD
  server failures rather than masking infrastructure problems.
- Adds regression coverage for both the safe HTTP 400 fallback and HTTP 500
  failure behavior.

This beta includes an updated TechBench Sync Service and is compatible with
database schema 15. Install `TechBenchServerSetup.exe` from this release to
apply the service fix; no SQL deployment is required.
