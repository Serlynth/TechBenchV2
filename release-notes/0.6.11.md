# TechBench V2 0.6.11

- Replaces the New Entry client ComboBox with a dedicated search field and
  separate suggestion popup.
- Up and Down now move through the suggestion list without invoking WPF's
  built-in ComboBox close behavior.
- Enter selects the highlighted client, while Escape or clicking elsewhere
  closes the suggestions.

This client update does not change TechBench Server or the database.
