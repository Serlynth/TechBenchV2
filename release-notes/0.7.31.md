# TechBench 0.7.31

- Adds **+ New client** to Client Information for admins creating a brand-new client without a migration workbook.
- Creates the shared internal client and blank Client Information profile as Live immediately, ready for manual entry in every client section.
- Keeps the initial review state Unverified until a technician reviews the manually entered information.
- Leaves Sage and Web Help Desk identities open for deliberate matching later while preserving the new internal client ID.
- Removes Live clients from the Workbook Imports list because they are already maintained directly in Client Information.
- Safely disables manual client creation when the matching server capability is not installed.

This Stable client release is paired with TechBench Server 0.6.25. Install the stable server package and apply its schema-15-compatible SQL update before using **+ New client**.
