# TechBench Inventory Beta 0.5.82-beta.1

- Automatically matches the build sheet's End User within the selected client.
- Prefers an exact email address, then an exact normalized name, then a
  confident name-word match that tolerates middle names, initials, titles, and
  reversed name order.
- Leaves the user unselected when multiple active client users are equally
  plausible.

This is a client-only beta update. It remains compatible with TechBench Server
0.5.81 and database schema 15.
