# TechBench V2 0.6.6-beta.6

- Makes each Client Information technology section contextual: **Add** and
  **Edit** now stay in the current category and show fields tailored to that
  kind of system or service.
- Adds suggested, editable record types and richer details for servers,
  WatchGuard/firewall and internet connections, Wi-Fi, cloud applications,
  domains and email, backup and security, and vendors.
- Adds an explicit **Move** action for correcting a record's category without
  losing its details or custom fields.
- Adds an **At-a-glance** card view to every technology section while
  preserving the existing full table and workbook import workflow.
- Pins a fictional, fully populated **Demo Client** to the top of the Client
  Information list. The sample is read-only, exists only in memory, and is
  excluded from SQL, matching, imports, exports, and attachment storage.
- Keeps the established migration-workbook columns unchanged so existing
  Client Information workbooks remain compatible.

This is a Client Info Beta client-only update. TechBench Server 0.6.13 and the
schema-version-15 SQL deployment remain current; no server or SQL update is
required.
