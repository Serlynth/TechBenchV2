# TechBench V2 2.0.0-alpha.17

Alpha.17 fixes the first real-server update failure found in alpha.16.

- The updater now restores inherited read-and-execute permission for the installed Windows service identity on the replacement service directory before attempting to start the service.
- This preserves the Administrator-only staging boundary while allowing `CSRI\TechBench_Sync` to load the replaced executable, dependencies, and `appsettings.json` after the directory swap.
- A regression test creates and inspects the resulting Windows ACL, and the package test still verifies the embedded one-click installer payload and version.
- If an update fails for another reason, the existing directory rollback behavior remains in place.

Database schema version 7 is unchanged. Existing SQL Server deployments do not need another database migration for alpha.17.
