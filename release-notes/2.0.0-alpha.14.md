# TechBench V2 2.0.0-alpha.14

Alpha.14 replaces the script-hosted TechBench Server Manager with a compiled, self-contained Windows application.

## Server Manager

- The Start Menu shortcut targets `TechBench.ServerManager.exe` directly. Opening the Manager no longer starts a PowerShell or VBScript launcher.
- The compiled Manager controls service start, stop, and restart; updates the Windows service identity; and rotates the existing machine-protected WHD and Sage secrets.
- Organization-wide WHD settings, Sage settings, synchronization requests, status, and AD-to-WHD technician mappings are managed in the compiled application through the existing Admin-only stored procedures.
- SQL Server name, database, and certificate-trust configuration can be saved and tested in the Manager. Windows integrated authentication remains mandatory.
- Minimizing or closing the window moves it to a real notification-area icon. Double-click the icon to reopen it; use its menu to control the service or exit.

## Updates and installation

- Future service and Manager updates are downloaded, checksum-verified, manifest-verified, schema-checked, installed, and rolled back by compiled code. Routine updates do not invoke PowerShell.
- The complete server ZIP includes `Install-TechBenchServerManager.ps1` for the one-time transition from an older script-based Manager. It verifies the packaged Manager files, installs them under Program Files, and creates a direct EXE shortcut without modifying the Windows service identity or protected credentials.
- The normal service installer also installs the compiled Manager and direct shortcut.
- Database schema version 7 remains required; this release has no SQL migration.

## One-time upgrade from alpha.9 through alpha.13

1. Download and extract the complete alpha.14 server ZIP on the server.
2. Open Windows PowerShell as Administrator in the extracted folder.
3. Run `Set-ExecutionPolicy -Scope Process Bypass -Force`.
4. Run `.\Install-TechBenchServerManager.ps1`.
5. In the compiled Manager, verify the SQL connection, select **Check for updates**, then **Download & Install** to update the service itself.

The one-time deployment script may use PowerShell; the installed Manager and all future routine Manager operations run as compiled Windows code.
