# TechBench 1.0.9

- Stops note selection from presenting the current time as a new save; each note now shows its persisted last-save time.
- Keeps the selected Client object stable while switching notes instead of clearing and rebuilding the dropdown.
- Opens the Client dropdown only for real keyboard input, not programmatic note loads.
- Reuses Ticket options while switching between notes for the same client to reduce database work and UI reloads.
