# TechBench 0.5.2

- Restores the established Sage customer normalization behavior in the server-owned 32-bit ODBC worker.
- Ignores Sage rows that have no usable customer ID because they cannot be represented or matched in TechBench.
- Uses the Sage customer ID as the display name when Sage returns a blank customer name, matching the earlier working client-side synchronization.
- Continues to reject duplicate customer IDs and over-length ID, name, contact, or telephone values before changing shared SQL data.

This fixes a regression where an unchanged Sage company could synchronize from the V1/client reader but the server-owned synchronization rejected the complete snapshot.

No SQL schema update is required.
