# TechBench V2 0.7.3

## WHD personal notes and images

- Renames the visible and posted personal-note heading to **Personal Note**
  without describing the note as Markdown.
- Keeps compatibility with personal notes posted by older TechBench versions.
- Adds temporary multi-image selection to the work-entry editor and uploads
  selected images directly to the resulting Web Help Desk TechNote.
- Does not save selected images or their local paths in TechBench or SQL.
- Removes successfully uploaded images from the selection while keeping failed
  images available for retry.

## Deployment

- This is a Stable client-only update. No TechBench Server or SQL update is
  required.
