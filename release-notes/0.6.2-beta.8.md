# TechBench V2 0.6.2-beta.8

This beta adjusts the Client Information categories based on technician
feedback.

- **Network & Internet** is renamed **Connection & Internet** throughout the
  Client Information editor and generated migration workbook.
- Switches are classified under **Servers & Infrastructure**, including older
  records and beta.7 workbooks that described them under Network & Internet.
- The Equipment description no longer lists servers.
- The `TB-CI-4` workbook includes the corrected category name and short category
  guidance on the Start Here sheet.
- Earlier `TB-CI-3`, `TB-CI-2`, and `TB-CI-1` workbooks remain importable.
- FireDrill remains available and unchanged during migration.

This is a client-only taxonomy update. It uses the existing schema 15 and does
not require another SQL update. Stable TechBench continues to work with the same
database.
