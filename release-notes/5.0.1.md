# TechBench 5.0.1

TechBench V2 now uses a conventional standalone release number beginning with 5.0.1. “V2” remains the product generation and is assumed rather than repeated in the release number.

This release includes all work completed through 2.0.0-alpha.25:

- Shared SQL Server storage and Windows domain authentication.
- Server-owned WHD and Sage synchronization.
- The native TechBench Server Manager and self-updating Windows service.
- Bulk AD-user-to-WHD-technician mapping with active technicians only.
- Mapping selections are saved with WHD settings and are preserved during refresh.
- Per-user Sage Activity Item IDs and the updated work-entry workflow.

Future maintenance versions will increment from 5.0.1. The database remains schema version 7 and this release does not add a database migration.
