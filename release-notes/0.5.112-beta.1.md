# TechBench V2 0.5.112-beta.1

- Makes **Mark Deployed** a client-only workflow that works with the current Stable TechBench server and schema 15.
- Stores deployed-device state in the existing shared organization settings, so all beta clients see the same status without a server, service, or SQL update.
- Removes deployed devices from the Equipment Board while keeping them searchable and editable in Inventory.
- Shows deployed status consistently in Inventory, client profiles, client-user equipment lists, and assignment history.
- Restores the existing Equipment Board and move procedure signatures for full compatibility with the Stable server.

This is a **client-only beta update**. Do not install a beta server package or apply a beta SQL script.
