# TechBench V2 2.0.0-alpha.8

## Server-owned synchronization

- Keeps organization-wide WHD synchronization in the Windows service, including the automatic five-minute schedule and Admin-only **Sync now** request.
- Moves shared Sage customer synchronization off Admin workstations and into the same Windows service through a durable, manual-only, Admin-requested SQL queue.
- Packages a self-contained x86 Sage ODBC worker so the x64 service can use the 32-bit Sage driver and server-local System DSN.
- Stores the server Sage DSN and username as Admin-managed SQL settings; stores the separate Sage password as machine-protected service-host data.
- Validates every Sage snapshot row before projection; empty, malformed, over-length, and duplicate-ID snapshots change no customer data.
- Requires a separate, warned Admin confirmation when a snapshot would remove at least 10 and at least 25 percent of an established Sage customer mapping set; approval is bound to the rejected request and exact rerun counts.
- Limits the service identity to the approved leased synchronization procedures.

## Admin user preview

- Adds an optional username field on the connection screen for TechBench Admins to preview a registered non-Admin user who has opened V2 within the past hour, ensuring preview eligibility is backed by a recent authorization refresh.
- Keeps Windows Integrated Authentication as the real login. Preview does not authenticate as the target user.
- Uses a short-lived server-authorized session, non-pooled connections, and a restricted `WITHOUT LOGIN` database user for read-only enforcement.
- Applies the target user's WHD technician/group visibility while redacting Personal Notes and detailed posting errors, denying editor drafts, withholding local credentials, and blocking all database mutations.
- Displays a persistent read-only preview warning in the window.

## Coordinated deployment

- Requires TechBench database schema version 7 (`SqlServer2016.ServerOwnedSageAndAdminPreview.0007`).
- Requires the matching alpha.8 client and alpha.8 TechBench Sync Service package; do not run mixed alpha clients during the cutover.
- Preserves the existing `TechBenchWhdSync` Windows service name and existing WHD credential during an in-place upgrade.
- Adds a masked-by-default Windows service-account password dialog with an explicit **Show password while I verify it** option; the installer does not write the password to the command line, configuration, or logs.
- Publishes predictable direct installer, service ZIP, and versioned standalone SQL assets with SHA-256 sidecars. The client release is published first, followed by the server and SQL assets on the same immutable GitHub release.
