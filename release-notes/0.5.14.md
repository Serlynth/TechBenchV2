# TechBench 0.5.14

## Safer Client Credentials workspace

- Search-result cards now display only the client name. Firebox IP, status, timestamps, and credential-like values are not exposed in the left list.
- Selecting a client immediately shows the complete field list on the right with every value masked as `***`.
- **Reveal Credentials** replaces the masks with the actual values returned by SQL Server.
- **Hide** restores the masks without changing the selected client.
- Copy buttons appear only while the values are revealed.

## Deployment

This release continues to use SQL schema version 8. No SQL migration is required when upgrading from 0.5.13. Install the 0.5.14 client through its built-in updater or `TechBenchV2Setup.exe`.
