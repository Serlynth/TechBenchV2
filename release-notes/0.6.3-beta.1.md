# TechBench V2 0.6.3-beta.1

This release republishes the Client Info beta.10 feature set on a version line
that the GitHub/Velopack prerelease feed orders correctly after
`0.6.2-beta.9`.

- Restores the normal in-app Client Info Beta update workflow from beta.9.
- Includes the category-specific IP and network columns introduced in beta.10.
- Includes controlled custom resource fields in Client Information and
  `Custom:` migration-workbook columns.
- Keeps `TB-CI-5` through `TB-CI-1` workbooks importable.
- Requires the matching schema-15-compatible SQL deployment to refresh Client
  Info procedures and grants.
- Stable TechBench, Server Manager, the Sync Service, and FireDrill remain
  compatible with the same database.
