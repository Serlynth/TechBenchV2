# TechBench V2 0.7.10

## Append-only WHD notes

- Simplifies WHD note handling to one verified post. TechBench no longer offers update, synchronization, conflict-resolution, or remote-delete actions for an existing WHD TechNote.
- Records the successful note and its exact WHD TechNote ID before image uploads begin, preventing an image failure from reopening the note or encouraging a duplicate post.
- After a note is posted, selected images can still be attached to that exact TechNote without reposting or changing its text.
- Keeps WHD- and Sage-posted TechBench entries and their posting history; only unposted drafts can be deleted.
- Treats older WHD synchronization errors as historical audit information instead of reopening already-posted work in the posting queue or daily closeout.

## Client Information

- Splits **Backup & Security** into separate **Backup** and **Security** tabs.
- Routes existing combined-category records automatically: backup, restore, replication, and disaster-recovery records go to Backup; antivirus, EDR, MFA, filtering, and monitoring records go to Security.
- Keeps the existing combined migration-workbook sheet compatible while importing its rows into the correct new tab.

## Deployment

- This is a Stable client-only update. No TechBench Server or SQL update is required.
