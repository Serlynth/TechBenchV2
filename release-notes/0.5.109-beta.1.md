# TechBench V2 0.5.109-beta.1

- Adds a visible **Mark Deployed** action to equipment in the Deployment section of the Equipment Board.
- Confirms the client, user, and location before completing deployment.
- Removes completed devices from the Equipment Board while retaining them in All Equipment, client profiles, and assignment history.
- Adds a Deployed status and filter to Inventory; deployed equipment remains editable there and is not archived.
- Records deployment completion with the acting TechBench user and timestamp in equipment assignment history.
- Preserves database schema 15 and Stable-client compatibility; Stable hides deployed devices from its Equipment Board.
- Database deployment required: apply the included `TechBenchV2-SQLServer2016-0.5.109-beta.1.sql` to `CSRI-SQL` before using Mark Deployed.
