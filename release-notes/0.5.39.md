# TechBench 0.5.39

- WHD technician synchronization now understands nested current-technician session responses and alternate direct current-account lookups used by WHD 12.x.
- The SQL ticket snapshot now recovers and activates assigned technicians omitted by WHD's normal `Techs` collection, including the organization administrator account needed for AD user mapping.
- Server Manager no longer labels a leased, actively running synchronization step as queued; it distinguishes active remaining work from work still waiting.
- Database schema remains version 12, but the matching 0.5.39 SQL deployment must be reapplied to install the technician-recovery procedure update.
