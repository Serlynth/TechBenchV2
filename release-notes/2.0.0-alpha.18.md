# TechBench V2 2.0.0-alpha.18

Alpha.18 fixes the Start Menu launch failure discovered after a successful alpha.17 server update.

- Server updates now grant the built-in Windows Users group inherited read-and-execute access to the installed Server Manager directory.
- Explorer can therefore resolve the direct EXE shortcut and display the Manager's required administrator-elevation prompt.
- SYSTEM and Administrators retain full control; ordinary users receive no write, modify, delete, ownership, or permission-management rights.
- Fresh/manual Manager installs apply the same ACL policy, and the Start Menu shortcut is recreated during update or repair.
- Existing service identity, SQL configuration, machine-protected WHD/Sage secrets, and rollback behavior are preserved.

Database schema version 7 is unchanged. Existing SQL Server deployments do not need another database migration for alpha.18.
