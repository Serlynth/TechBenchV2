# TechBench V2 0.6.2-beta.4

This beta fixes readability in the canonical Client Info editor.

- Replaces the Windows-default tab appearance with a TechBench-native tab
  template using the active dark or light theme colors.
- Gives selected, hovered, and disabled tabs explicit high-contrast states.
- Applies theme-aware backgrounds, text colors, borders, selection states, and
  column headers to every Client Info data grid.
- Keeps the separate **CLIENTS > Client Info (Beta)** workspace and leaves
  FireDrill behavior unchanged.

This is a client-only visual fix. It uses the existing schema 15 and does not
require another SQL update.
