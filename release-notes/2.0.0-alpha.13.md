# TechBench V2 2.0.0-alpha.13

## Windows PowerShell 5.1 SQL compatibility

- Fixes Server Manager SQL connection construction on Windows PowerShell 5.1. Dotted assignments on `System.Data.SqlClient.SqlConnectionStringBuilder` were incorrectly routed through its dictionary keyword setter and rejected `DataSource`.
- Uses canonical SQL Server connection-string keywords such as `Data Source`, `Initial Catalog`, and `Integrated Security` through the builder indexer.
- Adds regression coverage that forbids the incompatible dotted `DataSource` assignment.
- Preserves alpha.12's corrected GitHub release discovery and all alpha.11 shared WHD/Sage configuration functionality.

## One-time alpha.9 bootstrap

- Download and extract the alpha.13 service ZIP, close the installed alpha.9 Manager, and run `TechBench-ServerManager.ps1` from the extracted package as Administrator.
- In that Manager, select **Check for updates** and then **Download & Install**. Alpha.13 can verify schema version 7 with the current Windows identity, update the service, and repair the installed Manager launcher set.

## Deployment notes

- Requires database schema version 7 and introduces no SQL migration.
- Existing SQL configuration, service identity, and machine-protected WHD/Sage credentials are preserved.
