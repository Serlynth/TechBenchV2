# TechBench V2 2.0.0-alpha.16

Alpha.16 replaces the manual server bootstrap with a directly downloadable, self-contained `TechBenchServerSetup.exe`.

- Existing installations can be updated or repaired by running the setup EXE. It closes Server Manager, verifies the embedded package, preserves the Windows service identity, SQL configuration, and machine-protected WHD/Sage secrets, replaces the binaries, restarts the service, and opens the installed Manager.
- An existing installation may move between releases that require the same database schema without requiring the interactive setup operator to open SQL Server. A schema-version change still requires the matching DBA deployment and verification.
- Fresh installations use the same setup EXE and secure service-account password dialog; the operator no longer downloads, extracts, unblocks, or manually runs PowerShell scripts.
- SQL database-login failures now identify the exact Windows account and explain the `CSRI\TechBench_Admins` sign-out/sign-in requirement.
- The setup payload and every installed executable remain version- and SHA-256-verified before installation.

Database schema version 7 is unchanged. Existing SQL Server deployments do not need another database migration for alpha.16.
