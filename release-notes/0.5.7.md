# TechBench 0.5.7

This patch release corrects the SQL schema-8 verification stage shipped with
0.5.6. Legacy verification scripts now compare the
`GetRepositoryCapabilities` schema version without depending on whitespace in
the stored-procedure source text.

The FireDrill migration, database master key, encryption certificate, and
encrypted records installed by 0.5.6 are preserved. Rerun the complete 0.5.7
SQL installer in SQLCMD mode, then update the server and client packages.
