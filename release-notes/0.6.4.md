# TechBench V2 0.6.4

This corrective stable release supersedes the 0.6.3 server and SQL package.

- Corrects the final Client Info capability verification to compare the
  bracketed SQL identifier literally instead of treating it as a `LIKE`
  character class.
- Retains the 0.6.3 Equipment Board verification correction for the `Deployed`
  technician lane.
- Allows the complete idempotent SQLCMD deployment to reach and pass the final
  canonical Client Info security verification.
- Keeps Server Manager on one stable-only release line that supports both
  Stable and Client Info Beta desktop clients.

If 0.6.2 stopped with error 52220 or 0.6.3 stopped with error 52505, back up the
database and run the complete 0.6.4 SQLCMD bundle over it. Previously completed
migrations are recognized and preserved.
