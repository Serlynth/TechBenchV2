# TechBench 0.5.74

- Reorganizes Client Users into a clear three-stage workspace.
- Lists synchronized clients on the left and the selected client's users on the right.
- Opens a user in a slide-out details panel instead of permanently occupying the right side with one user's account fields.
- Keeps account values masked until explicitly revealed, with the existing non-blocking Copy controls.
- Preserves dynamic Client Users worksheet columns and searches across both client and user information.

This is a client-only update. The SQL schema remains version 14, and TechBench Server 0.5.73 remains compatible.
