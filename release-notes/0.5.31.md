# TechBench 0.5.31

- WHD technician synchronization now includes the authenticated organization administrator when WHD omits that account from the normal `Techs` list.
- The service follows the WHD 12.x API contract by creating a short-lived authenticated session, reading its `currentTechId`, retrieving that exact technician, and immediately terminating the session.
- The additional session is created only when the configured organization-wide WHD username is missing from the synchronized technician roster.
- This restores active accounts such as `WHDMgr` to Server Manager's AD-user-to-WHD-technician mapping list.
- This release continues to use SQL Server schema version 11; no SQL update is required when upgrading from 0.5.24 through 0.5.30.
