# TechBench V2 0.7.16

## ISP static addressing

- Adds an IP-assignment selector to Connection & Internet records for Dynamic, Single static, or Static block service.
- Adds the usable-static count plus either a copyable address list or first/last usable address range.
- Shows static-block details only when the selected ISP circuit uses them, while keeping single-static and dynamic circuits compact.
- Updates Demo Client with a valid five-address Comcast Business static block.

## Deployment

- This is a Stable client-only update. No TechBench Server or SQL update is required; server 0.6.16 and schema 15 remain current.
