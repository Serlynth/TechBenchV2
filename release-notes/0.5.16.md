# TechBench 0.5.16

## Clearer Credentials navigation

- The main sidebar now says **Client Credentials** instead of only **Credentials**.
- The navigation target and Client Credentials workspace are unchanged.

## Deployment

This release continues to use SQL schema version 8. No SQL migration or server-service update is required when upgrading from 0.5.15. Install the 0.5.16 client through its built-in updater or `TechBenchV2Setup.exe`.
