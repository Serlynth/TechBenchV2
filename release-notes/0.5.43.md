# TechBench 0.5.43

- Adds a **Credentials synchronization** card to the client Admin Center so TechBench Admins can request the existing server-owned workbook synchronization without signing in to the server.
- Shows live queued/running progress in the Admin Center, polling SQL Server every second until the synchronization completes or fails.
- Displays final workbook counts for rows read, saved, and marked stale, plus queue depth and last-attempt/last-success timestamps.
- Uses the existing schema-12 Credentials queue and Sync Service worker; no SQL schema update is required for this release.
