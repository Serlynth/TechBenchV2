# TechBench 0.5.41

- Redesigned the connection window as a compact branded TechBench sign-in card with clearer server, database, Windows identity, status, update, and connection controls.
- Removed the Admin read-only preview controls from the login screen.
- TechBench client connections now always trust the configured internal SQL Server certificate without showing a certificate checkbox.
- Client Credentials now groups related fields beneath clear provider headings such as **WatchGuard**, **Microsoft 365**, **ESET**, and **Barracuda**, while preserving unknown workbook columns under **Other**.
- New provider username/password pairs can form their own section automatically without requiring another database schema change.
