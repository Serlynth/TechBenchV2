# TechBench Inventory Beta 0.5.68-beta.1

- Removes the left and right technician arrow buttons from the Inventory Board; technician columns are rearranged by dragging.
- Replaces the technician hide X with an eye-style visibility control.
- Adds a technician-header preview that follows the pointer while a column is being dragged.
- Makes the live Equipment Details editor match Demo Mode: it overlays the board only while editing and closes without leaving an empty tray or rail.

No SQL schema or Server Manager update is required for this release.
