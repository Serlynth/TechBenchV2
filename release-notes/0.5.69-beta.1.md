# TechBench V2 0.5.69-beta.1

- Removed technician lanes for users who are no longer members of the authorized TechBench Active Directory groups.
- Server Manager now reconciles the complete authorized-user list after a successful AD refresh.
- Retired users lose their TechBench roles and WHD technician mappings in one audited SQL transaction.
- Empty, invalid, or unavailable AD snapshots fail closed and cannot retire existing users.

Install TechBench Server 0.5.69 before using this beta so the updated Server Manager and SQL procedure are available.
