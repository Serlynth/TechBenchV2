# TechBench V2 0.6.6-beta.9

- Replaces the item-by-item Client Information overview with a bounded,
  category-level dashboard of the details technicians are most likely to need.
- Uses the kinds of fields established by FireDrill as a design guide while
  reading only the canonical Client Information records; FireDrill data is not
  copied into or queried by the overview.
- Gives each category purpose-built summaries, including infrastructure and
  management, firewall and WAN addressing, wireless, cloud applications,
  domains and email, backup and security, and vendor support.
- Caps repeated values at three and sends the technician to the full list for
  the remainder, so adding many records cannot create an equally large stack of
  overview cards.
- Keeps protected access references concise and never displays secret values.
- Corrects the full-list custom DataGrid styling so its background, rows, text,
  headers, and selection remain readable in the dark theme.

This is a Client Info Beta client-only update. TechBench Server 0.6.13 and the
schema-version-15 SQL deployment remain current; no server or SQL update is
required.
