# TechBench 0.5.77

- Adds the complete synchronized Client Users list to the full client profile opened by double-clicking a client.
- Lets technicians select a user within the client profile and reveal that user's protected account details without leaving the profile.
- Keeps synchronized user account values masked until explicitly revealed and supports the existing asynchronous Copy behavior.
- Preserves the client profile when user enrichment is unavailable, so inventory and client information still open normally.

This is a client-only update. It remains compatible with TechBench Server 0.5.76 and database schema 15.
