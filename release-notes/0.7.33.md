# TechBench 0.7.33

- Temporarily hides the Client Information Equipment tab while preserving its implementation for the planned redesign.
- Makes large selected-record summaries scroll smoothly in Servers & Infrastructure and Connection & Internet.
- Improves Client Information list readability with a narrower server Type column, shorter Connection headings, and taller wrapped Wi-Fi and Security headings.
- Shortens the Users license heading and removes the leading `Microsoft` label from displayed Microsoft 365 license names.
- Formats standard AnyDesk IDs as `### ### ###` or `1 ### ### ###` throughout TechBench while preserving aliases and nonstandard addresses.
- Adds one-click copying for credential Login URLs from the Passwords tab.
- Replaces the free-text Other Information value type with valid choices and keeps the editor open, with all entered data intact, when validation or saving fails.

This Stable client release is paired with TechBench Server 0.6.27, which repairs the rerunnable SQL upgrade path from Server 0.6.26.
