# TechBench V2 0.7.14

## This Week and History editor

- Adds **More** directly to the inline editor in both **This Week** and **History**, with the same link, duplicate, and delete actions as the full editor.
- Makes the inline editor pane horizontally resizable and remembers the chosen width across both views and future launches.
- Keeps the active week, history range, filters, and selected list position in place while editing or deleting an entry.

## TechBench-only deletion after WHD posting

- Allows a WHD-posted entry that has not been posted to Sage to be deleted from TechBench after an explicit local-only confirmation.
- Never contacts, changes, or deletes anything in WHD during this action. If the WHD note still exists, it remains there.
- Keeps Sage-posted entries permanently locked and keeps active or uncertain posting attempts protected from deletion.
- Restores an undone deletion as an unposted TechBench draft rather than reconnecting stale WHD tracking.

## Deployment

- Update the shared database with the matching **TechBench Server 0.6.16** standalone SQL deployment, then update workstations to Stable **0.7.14**.
- The database remains schema version 15. The SQL update only replaces the guarded work-entry deletion procedure and its verification; it does not add WHD edit/delete synchronization.
