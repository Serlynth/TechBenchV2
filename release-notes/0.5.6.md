# TechBench 0.5.6

- Adds a shared **Credentials** workspace backed entirely by SQL Server for the password-encrypted `FireDrill.xlsx` workbook.
- Allows every authenticated member of `CSRI\TechBench_Users` and `CSRI\TechBench_Admins` to search client names, explicitly reveal credentials, and copy individual fields.
- Encrypts all imported credential values with an AES-256 SQL Server symmetric key protected by a database certificate; the client never stores the workbook or its credentials locally.
- Records every reveal and field-copy action in the TechBench SQL audit trail. Admin read-only user preview cannot access credentials.
- Adds a server-owned, read-only workbook import that can read while another employee has the file open, rejects changing or malformed snapshots without altering SQL data, and retries later after sharing/save conflicts.
- Schedules the import once daily at 4:00 AM server local time and lets only TechBench Admins change the path/schedule or queue an immediate sync.
- Adds a **FireDrill** tab to TechBench Server Manager for the UNC path, schedule, sync status, and machine-protected workbook password.

This is a coordinated schema, server, and client release. Version 0.5.6 requires SQL schema version 8. Apply the included SQL deployment before updating the server and client.
