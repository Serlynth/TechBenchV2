# TechBench V2 2.0.0-alpha.4

This candidate makes the shared-administration boundary explicit throughout the client and SQL Server contract.

## Changes

- Restricts organization-wide configuration and WHD/Sage synchronization to TechBench Admins. This includes shared customer matching and aliases, Common Links, note templates, connection defaults, and synchronization controls.
- Stores the WHD automatic-sync enabled state and interval as server-backed organization settings so every administrator sees the same schedule. The workstation refresh interval remains a local preference.
- Changes shared WHD ticket synchronization from the technician-only My Tickets feed to the organization ticket query. Explicit closed/deleted tickets update shared state, while a ticket missing from a response is never closed by inference; the configured WHD identity must be a WHD Admin with access to the full ticket set.
- Adds an Admin-managed common-tag catalog. Ordinary work-entry saves no longer publish new shared suggestions automatically.
- Allows Admins to edit built-in Common Links while preserving their identity and order; built-in links remain protected from deletion.
- Removes the redundant manual Sage customer-mapping controls from Settings. Administrators manage shared customer matching from the dedicated client-matching workspace.
- Retires the copied V1 client-side SQLite backup implementation and its update-time backup path. TechBench V2 does not create local business-database backups.
- Adds a release-build guard that rejects SQLite libraries, SQLite dependency-manifest entries, and `.db` files before packaging.

## Deployment note

This client requires the matching SQL Server 2016 schema-version-4 deployment and its administrator-only shared-configuration contract. Have the DBA back up `TechBench`, rerun the complete standalone SQLCMD deployment, and install alpha.4 as one coordinated test cutover. SQL Server backup, integrity-check, retention, and restore operations remain DBA responsibilities; the TechBench client does not perform them.
