# TechBench 0.7.25

- Names the exact workbook sheet and row for every unverified Client Information record.
- Adds **Accept Remaining as Keep as-is** so an authorized migration operator can explicitly accept remaining unverified rows without editing and importing another workbook revision.
- Adds **Discard Review** for canceling an unpromoted workbook import without changing Client Information.
- Makes **Refresh Checks** rerun validation and the FireDrill comparison instead of only reloading old results.
- Disables approval while unverified or Needs review rows still require action.
- Keeps only the newest unfinished revision of a workbook in the active review list.

This release is paired with TechBench Server 0.6.21. Apply the stable 0.6.21 SQL update once on the shared TechBench server before using the new review actions.
