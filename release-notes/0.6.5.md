# TechBench V2 0.6.5

- Remembers the last normal window size and position and restores a maximized
  workspace as maximized on the next launch.
- Saves the window state before an in-app update restarts TechBench.
- Brings the connection screen and workspace to the foreground after an update
  instead of leaving TechBench minimized or hidden behind other windows.
- Reopens the last TechBench, AdminBench, or SalesBench module and the last
  workspace page used in TechBench or AdminBench.
- Uses the remembered module's logo and blue, green, or red accent palette on
  the connection screen before sign-in.
- Falls back to TechBench and a valid default page when the saved module is not
  available to the current Windows user or a saved page no longer exists.

This is a Stable client-only release. It does not require a TechBench server or
SQL update. It includes the Stable 0.6.4 client and shared schema compatibility
baseline.
