# TechBench 5.0.3

Version 5.0.3 is a one-time numbering-transition bridge for installations that received the mistakenly numbered 5.0.1 or 5.0.2 releases.

- Client updates move to the dedicated TechBench V2 release channel and permit the intended transition onto the lower-numbered 0.5.x development line.
- Server Manager recognizes the corrected 0.5.x line as newer than the earlier 2.0.0-alpha.x and 5.0.x numbering.
- No application data, SQL data, credentials, or local preferences are changed by the numbering transition.

After installing this bridge, update once more to 0.5.1. All subsequent development releases increment from 0.5.1.
