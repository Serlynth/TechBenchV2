# TechBench V2 0.7.13

## Linked access during manual add

- Adds separate **Details** and **Username & password** tabs when manually adding a system or service from any Client Information category.
- Automatically creates and links the optional login to the exact newly saved system using its internal resource ID.
- Stores the password through the existing encrypted Client Information secret store; it is never copied into ordinary object fields or notes.
- Leaves both fields optional, including username-only and password-only logins.
- Keeps the master **Passwords** workflow for adding a login first and manually choosing its linked system or service.
- Clearly reports partial success if the system saves but its login or password cannot be completed, so the saved object is not accidentally duplicated.

## Independent client windows

- Client profile windows no longer stay forced above the main TechBench workspace.
- You can return to the main window, browse other TechBench areas, and open another client while existing client profiles remain open.

## Deployment

- This is a Stable client-only update. No TechBench Server or SQL update is required.
