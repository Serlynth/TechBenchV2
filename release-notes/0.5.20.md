# TechBench 0.5.20

This coordinated client, server, and SQL release adds a safe recovery path for deleting a local work entry after its exactly tracked Web Help Desk TechNote has already been deleted in WHD.

- **Delete Entry** becomes available only after TechBench has queried WHD and saved the explicit result that the tracked TechNote was not found.
- SQL Server independently requires the owner, the matching failed WHD tracking log, its `WHD-TECHNOTE-*` external reference, and explicit confirmation from the client.
- Sage-posted entries and WHD-posted entries without that verified evidence remain locked.
- Undo restores the deleted item as a fresh local entry without claiming that the removed WHD TechNote still exists.

This release requires SQL schema version 9. Back up `TechBench`, apply the matching SQL installer in SSMS with SQLCMD mode enabled, then update the server package and client to 0.5.20.
