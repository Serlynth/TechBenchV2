# TechBench V2 0.7.2

## Client locations and users

- Splits the combined People & Locations area into dedicated **Locations** and
  **Users** sections.
- Expands each user record with Active Directory username and password,
  Microsoft 365 assignment and license, email address, and PC name.
- Keeps AD passwords in the encrypted credential store while making them
  available through the normal reveal and copy controls.
- Updates Client Information workbook templates and imports for the expanded
  user fields.

## Client overview links

- Replaces the large Canonical Summary box with a compact client-description
  field.
- Adds saved server links for the client's folder and legacy Client Info sheet.
- Opens UNC paths, local paths, and URLs directly from the client Overview.
- Identifies the legacy sheet as a read-only reference after migration.

## Server compatibility

- Install TechBench Server `0.6.14` and apply its schema-15 SQL deployment
  before saving the new Overview links.
