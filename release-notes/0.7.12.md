# TechBench V2 0.7.12

## Cleaner contextual passwords

- Removes the redundant **Passwords & access** pane from Client Information category tabs.
- Restores the selected-record summary to the full available width.
- Keeps passwords, usernames, Reveal, and Copy actions directly in the selected record's useful category summary.
- Includes every explicitly linked active login in that one summary without duplicating credentials already represented by category-specific fields.
- Keeps the master **Passwords** tab and its linked **System / user** column.

## Deployment

- This is a Stable client-only update. No TechBench Server or SQL update is required.
