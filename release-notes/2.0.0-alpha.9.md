# TechBench V2 2.0.0-alpha.9

## TechBench Server Manager

- Adds a small administrator-only Windows GUI for the TechBench Sync Service.
- Shows the installed service version, Windows identity, current state, and whether the WHD and Sage protected credentials are configured.
- Provides Start, Stop, Restart, and Refresh controls without exposing broader Windows service-management access.
- Separates the Windows service-account password, WHD API secret, and Sage ODBC password; fields are masked by default and can be revealed while verifying an entry.
- Keeps WHD URL/username, Sage DSN/username, schedules, mappings, and other organization settings Admin-managed in SQL Server through the TechBench client.

## Server-service updates

- Checks the public TechBench V2 release feed for a newer compatible service package from a button.
- Verifies the release URL, exact versioned asset names, SHA-256 sidecar, safe ZIP layout, and every file recorded in the package manifest before changing the installation.
- Requires the package's declared SQL schema version to match the live TechBench database before stopping the service.
- Preserves the existing Windows service registration and password, exact `appsettings.json`, service state, and machine-protected WHD/Sage secrets during routine updates.
- Stages the new payload, keeps a rollback copy, restarts and stability-checks the service, and automatically restores the prior payload when an update fails.
- Warns explicitly that the current alpha packages are not digitally signed; SHA-256 validation detects corruption but is not a Windows publisher signature.

## Deployment

- Requires TechBench database schema version 7. No new database migration is introduced in alpha.9.
- Requires one manual alpha.9 service-package installation to add TechBench Server Manager to the server. Later service updates can be installed from the Manager.
- Revalidates the extracted first-install package in protected administrator-only staging before changing the Windows service.
- Installs a **CSRI > TechBench Server Manager** Start Menu shortcut and preserves the existing `TechBenchWhdSync` service name.
- Keeps the alpha.9 client, service, and SQL installer as a coordinated release while preserving the separate V1 application unchanged.
