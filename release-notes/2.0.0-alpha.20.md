# TechBench V2 2.0.0-alpha.20

Alpha.20 corrects normal WHD ticket visibility and removes duplicated server-owned integration settings from the client.

- The normal Ticket List is scoped to the current user's mapped WHD technician and synchronized technician groups, including when the user is a TechBench Admin.
- Admins use the explicit read-only user preview when they need to inspect another technician's workspace.
- Client Settings show only personal WHD posting credentials and workstation-specific Sage posting/verification inputs.
- Shared WHD URL/authentication, Sage activity/billing configuration, and organization synchronization remain Server Manager-only.
- Sage validation now directs users to Server Manager when the shared activity item is missing.

The database remains schema version 7, but the matching alpha.20 SQL deployment must be run once to refresh the ticket-read stored procedures. Existing data and mappings are preserved.
