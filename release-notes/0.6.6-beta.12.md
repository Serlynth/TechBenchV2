# TechBench V2 0.6.6-beta.12

- Trims the Microsoft 365 quick-reference card to the tenant, admin portal,
  and the access records technicians use most often.
- Trims the Domain & AD quick-reference card to the domain, domain
  controllers, admin URL, and relevant access records.
- Replaces the vague stored-secret count with the named credential, username,
  login URL, and direct Reveal and Copy actions in both Client Information
  quick-reference views.
- Keeps password values encrypted until a technician requests them and retains
  the existing AuthPoint authorization and audited Reveal/Copy workflow.
- Keeps all omitted details available in the comprehensive category lists and
  Passwords tab.

This is a Client Info Beta client-only update. TechBench Server 0.6.13 and
schema version 15 remain current; no server or SQL update is required.
