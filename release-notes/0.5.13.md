# TechBench 0.5.13

## Credentials workbook row handling

- Rows without a Client value are now skipped instead of rejecting the entire Credentials snapshot.
- Values, formulas, or notes left in the other columns of an unassociated row no longer prevent valid client rows from importing.
- Rows with a Client value retain the existing duplicate, length, header, password, and atomic-snapshot validation.

## Deployment

This release continues to use SQL schema version 8. No database migration is required when upgrading from 0.5.12.

Run `TechBenchServerSetup.exe` as Administrator on the service host. After the service restarts, open **Credentials**, select **Sync now**, and confirm that health changes to **Completed** with a nonzero imported-row count.
