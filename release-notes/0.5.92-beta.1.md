# TechBench Inventory Beta 0.5.92-beta.1

- Fixes the interface error that appeared when opening an inventory item from
  a popped-out client overview.
- Keeps the equipment details inside that client profile as intended.
- Adds regression coverage for the read-only assignment label binding that
  caused the failure.

This is a client-only beta update. It remains compatible with TechBench Server
0.5.81 and database schema 15.
