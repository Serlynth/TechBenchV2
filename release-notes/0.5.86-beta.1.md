# TechBench Inventory Beta 0.5.86-beta.1

- Makes Inventory the only section where equipment records can be added,
  imported, edited, saved, or archived.
- Keeps Equipment Board focused on technician assignment, ordering, and
  deployment drag-and-drop.
- Opens read-only equipment details without leaving Equipment Board, Client
  Users, or another current view.
- Keeps equipment details inside the full client profile pop-out when a device
  is selected there.
- Adds Copy details to equipment trays and selectable values in the full client
  profile, while excluding the AnyDesk password from bulk copy.
- Routes the read-only tray's edit action to Inventory.

This is a client-only beta update. It remains compatible with TechBench Server
0.5.81 and database schema 15.
