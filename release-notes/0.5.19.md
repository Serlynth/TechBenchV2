# TechBench 0.5.19

## Client/server synchronization boundary

- **Test My WHD Posting Access** now authenticates through WHD's dedicated Session resource. It no longer reads `Tickets/mine`, downloads a sample ticket, or presents the test as a ticket synchronization.
- Auto-detection of each user's WHD password/API-key format uses the same ticket-free Session authentication check before the user's first posting operation.
- **Use another WHD ticket** resolves the ticket from the server-synchronized SQL inventory instead of querying WHD directly from the workstation.
- The workstation Sage customer-table test has been removed. Shared Sage customer synchronization remains manual and server-service-owned; workstation Sage settings remain available only for the user's Sage time-ticket creation and verification workflow.
- Regression tests enforce that the desktop view model does not invoke WHD organization synchronization, direct WHD ticket lookup, or Sage customer-table reads.

This release continues to use SQL schema version 8. No SQL migration is required when upgrading from 0.5.18. Install the 0.5.19 client through its built-in updater. The coordinated server artifacts are republished at the same version, but the synchronization-service behavior and database schema are unchanged.
