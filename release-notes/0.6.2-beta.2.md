# TechBench V2 0.6.2-beta.2

This update makes the canonical Client Info beta available through the same
opt-in channel workflow used by the previous Inventory Beta.

- Stable 0.6.2 users can select **Use Client Info Beta update channel** and
  install this beta through **Check for Updates**.
- Beta users can clear the selector and return to Stable through the normal
  updater.
- Stable and beta builds share the normal TechBench installer identity while
  continuing to use separate release channels.
- Retains the canonical Client Info schema, encrypted credentials, per-client
  workbook staging, FireDrill comparison, approval, promotion, provenance, and
  row-version conflict handling introduced in beta.1.
- Keeps SQL schema version 15 so stable 0.6.1 and 0.6.2 clients remain
  compatible with the same database.

The current Stable 0.6.2 Server Manager or standalone SQL bundle must be
applied once before canonical Client Info is opened. The server does not use a
beta channel and supports both desktop channels. FireDrill remains operational
during beta migration.
