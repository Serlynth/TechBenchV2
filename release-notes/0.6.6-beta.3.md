# TechBench V2 0.6.6-beta.3

- Prevents Sage lookup fields from accepting a valid short prefix while a
  longer Employee ID, Customer ID, or Activity Item is still being typed.
- Sends each complete identifier to Sage as one atomic field update before
  triggering Sage validation.
- Reads the identifier back both before and after validation and continues to
  refuse Save if Sage returns a different value.
- Fixes Customer ID `19555` being truncated and validated as Customer ID `195`.

This is a client-only Client Info Beta update. No TechBench server or SQL update
is required.
