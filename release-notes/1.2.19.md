# TechBench 1.2.19

- Renames Work Note to **Sage/WHD Note** and Internal Note to **Personal Note** throughout the app.
- Adds a per-entry option to include the Personal Note in WHD; it is off by default and Sage never receives it.
- Rebuilds client synchronization around WHD company locations instead of individual WHD users.
- Adds a Client Matching workspace with exact consolidation, reviewed fuzzy suggestions, and safe record merging.
- Adds first-run database location choice plus Settings commands to move the database or use an existing TechBench database.
- Keeps a verified pre-move backup and the prior database file for rollback.
