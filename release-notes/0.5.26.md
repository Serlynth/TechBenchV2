# TechBench 0.5.26

## WHD work-date correction

- Web Help Desk TechNotes now use the TechBench entry's Work Date as the WHD note date override instead of inheriting the current posting date.
- Entries with a start/end time use the Work Date plus the entry's start time for the WHD TechNote timestamp.
- Duration-only entries use noon on the selected Work Date so timezone conversion cannot move the note onto an adjacent date.
- Later synchronization of an already tracked WHD TechNote also preserves the entry's Work Date and start time.

This release continues to use SQL schema version 11. No SQL change is required from TechBench 0.5.24 or 0.5.25.
