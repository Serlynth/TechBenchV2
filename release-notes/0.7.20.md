# TechBench 0.7.20

- Adds a per-user **Microsoft 365 and AD use the same login** checkbox in Client Information.
- Shows a separate Microsoft 365 username and password only when that checkbox is cleared.
- Stores the separate Microsoft 365 login as a credential linked to the same user, while preserving the existing AD login.
- Deactivates rather than erases a separate Microsoft 365 login when a user switches back to the AD credential.
- Updates the Client Information migration workbook to `TB-CI-9` with Microsoft 365 login-reuse, username, and password columns beside each user.
- Keeps migration workbooks from `TB-CI-8` through `TB-CI-1` importable.
