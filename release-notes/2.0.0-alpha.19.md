# TechBench V2 2.0.0-alpha.19

Alpha.19 fixes the Windows-authenticated client connection screen on smaller and high-DPI desktops.

- The connection form is resizable and scrollable, with larger readable text and fields.
- **Connect with Windows** and **Cancel** remain visible in a fixed action bar.
- The optional Admin read-only user preview stays collapsed until selected.
- Enter activates the visible connection action when the saved server and database are already populated.
- A successful connection no longer allows WPF to shut down the process before the main TechBench workspace opens.

The database remains schema version 7. The alpha.18 Sync Service and SQL installation remain compatible and do not need to be updated for this client-only release.
