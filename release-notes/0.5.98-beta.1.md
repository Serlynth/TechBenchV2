# TechBench V2 0.5.98-beta.1

- Adds private beta module switching for the authenticated `CSRI\rskoog` Windows account only.
- Adds independent TechBench, SalesBench, and AdminBench application shells.
- Keeps the shared CSRI logo mark while changing the module name in the sidebar branding.
- SalesBench uses a green accent palette and AdminBench uses a red accent palette in both dark and light themes.
- SalesBench and AdminBench have separate, intentionally empty sidebars ready for future module-specific navigation.
- All other users remain in the unchanged TechBench shell and cannot see or activate the module switcher.
- Client-only beta update. No server or SQL deployment is required.
