# TechBench V2 2.0.0-alpha.1

Initial direct SQL Server foundation:

- Isolated V2 desktop identity, credentials, mutex, packaging, and update path
- Direct encrypted SQL Server connectivity through `Microsoft.Data.SqlClient`
- Windows Integrated Authentication with no TechBench password
- Locally saved server/database connection settings containing no credentials
- Database schema-version and current-user role checks at startup
- Shared-client reads through `[tb_app].[SearchClients]`
- SQL Server 2016 compatibility-level-130 DBA deployment scripts
- Removal of the ASP.NET API, PostgreSQL, Identity login, Docker, and token client
- Independent V2 Velopack automatic-update feed and package identity

This Phase 1 alpha does not yet move Today, history, tickets, templates,
settings, drafts, posting, synchronization, or imports fully onto SQL Server.
Those V1-derived workflows remain transitional and are not production-ready.
