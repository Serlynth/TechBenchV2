# TechBench 1.0.7

- Keeps edited notes unsaved until Save is explicitly selected; background recovery copies no longer create or update work entries.
- Clearly labels recovery copies as unsaved so draft protection cannot be mistaken for a committed note.
- Speeds up note switching by removing redundant client lookups and limiting recent-client-note queries to five rows.
- Preserves crash and close recovery for unfinished notes without changing WHD or Sage posting behavior.
