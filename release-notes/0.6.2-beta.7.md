# TechBench V2 0.6.2-beta.7

This beta separates the broad Systems & Services area into focused categories.

- Client Information now uses a left-side category menu for Overview, People &
  Locations, Equipment, Servers & Infrastructure, Network & Internet,
  Applications & Cloud, Domains & Email, Backup & Security, Vendors & Services,
  Passwords, and Other Information.
- Antivirus and EDR records belong under **Backup & Security**.
- Existing records are categorized from their current resource type. Anything
  unclear remains visible under **Needs Sorting** and can be recategorized while
  editing it.
- The `TB-CI-3` migration workbook uses matching category tabs so information is
  organized the same way during import and after promotion.
- Earlier `TB-CI-2` and `TB-CI-1` beta workbooks remain importable.
- Equipment displayed in Client Information is the same shared equipment used
  by the existing Inventory workspace.
- FireDrill remains available and unchanged during migration.

This is a client-only organization update. It uses the existing schema 15 and
does not require another SQL update. Stable TechBench continues to work with the
same database.
