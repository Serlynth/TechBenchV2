# TechBench V2 2.0.0-alpha.15

Alpha.15 fixes compiled Server Manager compatibility with JSON files written by Windows PowerShell 5.1.

- The Manager now accepts UTF-8 configuration and package-manifest files both with and without a byte-order mark.
- This fixes the startup and **Save & Test** error: `'0xEF' is an invalid start of a value`.
- The fix covers `appsettings.json`, downloaded `package-manifest.json`, and the installed-manifest update path so updates and rollback cannot hit the same encoding failure later.

Database schema version 7 remains required. This release has no SQL migration.
