# TechBench 0.5.48

- Adds a third Admin Center synchronization card for the shared Credentials workbook.
- **Sync Credentials now** queues the same server-owned job as **Credentials → Sync now** in TechBench Server Manager.
- Shows queued, running, completed, failed, row-count, and timestamp status in the Admin Center.
- Uses the Admin Center's existing refresh cycle instead of a separate tight polling loop, and isolates Credentials status failures so they cannot block workspace startup.
- Improves SQL database-open errors by identifying stale Windows group tokens and explaining the required Windows sign-out/sign-in.
- No SQL schema update is required.
