# TechBench 1.2.0

- Adds a Common Links workspace under Directory.
- Includes starter links for WatchGuard Cloud, Microsoft 365 Admin Center, and Barracuda Cloud Control.
- Supports adding, editing, opening, and removing custom links.
- Accepts only HTTP and HTTPS addresses and opens links in the Windows default browser.
- Seeds starter links once, so links you remove stay removed.
