# TechBench V2 0.6.2-beta.5

This beta turns Client Info migration into two distinct workflows.

- **CLIENTS > Workbook Imports** guides the user through choosing a client,
  creating a migration workbook, importing it, reviewing validation and
  FireDrill comparison results, approving it, and adding it to Client
  Information.
- **CLIENTS > Client Information** is now only for viewing and editing records
  that are already stored in canonical SQL tables.
- The new `TB-CI-2` migration workbook uses seven plainly named tabs and removes
  technical row-key columns. It adds dedicated Equipment and Passwords tabs,
  simple review-status fields, visible instructions, and the internal client ID.
- Earlier `TB-CI-1` beta workbooks remain importable.
- FireDrill remains available and unchanged during migration.

This is a client-only workflow update. It uses the existing schema 15 and does
not require another SQL update. Stable TechBench continues to work with the
same database.
