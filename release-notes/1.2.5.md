# TechBench 1.2.5

- Adds a persistent Chrome Incognito option to the built-in Microsoft 365 Admin shortcut.
- Resolves Chrome from registered and standard Windows install locations without changing the system default browser.
- Passes `--incognito` and the destination URL as separate process arguments.
- Shows a styled TechBench error instead of falling back to a normal browser when Chrome cannot be found or started.
