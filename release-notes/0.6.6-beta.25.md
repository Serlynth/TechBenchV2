# TechBench V2 0.6.6-beta.25

- Changes each Client Information category's top panel from an all-category
  overview to a summary of the record selected in the Full list.
- Selects the first record by default and updates the panel immediately when a
  different row is selected.
- Keeps the main Technician Quick Reference client-wide and independent of
  category row selection.
- Keeps linked and recognizable legacy credentials with the selected record's
  summary.

This is a Client Info Beta client-only interaction update. TechBench Server
0.6.13 and schema version 15 remain current; no server or SQL update is
required.
