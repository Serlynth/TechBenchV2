# TechBench V2 0.6.6-beta.10

- Places the actual FireDrill information groups into fixed Client Information
  overview sections: WiFi, WatchGuard, Microsoft 365, ESET, Barracuda, Veeam,
  Domain & AD, Remote Access, ILO / iDRAC, and UPS.
- Keeps each group in its appropriate canonical category instead of creating
  dynamic Client Information sections.
- Uses FireDrill's real known-group matching rules to recognize canonical
  resources and access records, while continuing to read only Client
  Information data rather than the FireDrill workbook or cache.
- Adds the important fields technicians expect for each group, plus useful
  canonical details such as addressing, hardware, support, scope, schedules,
  retention, restore testing, and renewals.
- Makes every overview value selectable read-only text so it can be copied with
  mouse selection, right-click Copy, or Ctrl+C without a wall of Copy buttons.
- Enables normal DataGrid copying with column headers in each category's full
  list.

Secret values remain in the audited Passwords workflow and are not exposed by
the overview. This is a Client Info Beta client-only update. TechBench Server
0.6.13 and schema version 15 remain current; no server or SQL update is needed.
