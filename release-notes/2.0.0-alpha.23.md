# TechBench V2 2.0.0-alpha.23

Alpha.23 completes several client and server workflow improvements.

- Saving an edited work entry now returns the client to a clean New Entry form.
- Each user now has their own Sage Activity Item ID; it is no longer shared organization-wide or configured in Server Manager.
- Server Manager replaces the one-user-at-a-time WHD mapping controls with a single bulk mapping table.
- The mapping table automatically lists members of `CSRI\TechBench_Users` and `CSRI\TechBench_Admins`, identifies Admins, and removes duplicate users.
- Only active WHD technicians appear as mapping choices.
- An Admin can map every authorized AD user before those users have opened TechBench, then save the full mapping set together.

The database remains schema version 7, but the matching alpha.23 SQL deployment must be run once before using the new bulk mapping screen and per-user Sage Activity Item ID. Existing users, tickets, work entries, and valid WHD mappings are preserved.
