# TechBench V2 0.7.11

## Passwords beside their systems

- Keeps the **Passwords** tab as the complete master list for the client.
- Adds a **Passwords & access** panel beside the highlighted record in every technology category, showing all logins explicitly linked to that system or service.
- Shows usernames, login URLs, and every current secret with inline Reveal and Copy actions; linked credentials can be edited directly from the contextual panel.
- Identifies the linked system or user in the master Passwords list and clearly labels legacy records that have not been linked yet.
- Uses exact stored links and does not guess which object owns an unlinked credential.

## Deployment

- This is a Stable client-only update. No TechBench Server or SQL update is required.
