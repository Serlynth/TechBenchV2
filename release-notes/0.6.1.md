# TechBench V2 0.6.1

- Renames the Clients navigation group to FireDrill to match the synchronized
  workbook.
- Generates FireDrill subsections automatically from distinct workbook columns
  that share a meaningful leading keyword.
- Groups ILO, UPS, and future repeated keywords without requiring application
  changes when new columns are added.
- Keeps Overview, Users, and Common Links fixed while placing unmatched or
  single fields under Miscellaneous.
- Prevents repeated client rows and generic words such as User, Password, and
  IP from creating misleading navigation categories.
