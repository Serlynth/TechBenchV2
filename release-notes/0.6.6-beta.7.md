# TechBench V2 0.6.6-beta.7

- Replaces the Client Information **At-a-glance** checkbox with a permanent
  split layout in every technology and service category.
- Keeps useful overview cards in the upper pane and the complete sortable
  field list in the lower pane, so technicians can scan and work with the
  detailed records at the same time.
- Synchronizes selection between the overview and full list; cards and rows
  can both be double-clicked to edit.
- Adds a draggable horizontal divider for adjusting how much room each pane
  receives.

This is a Client Info Beta client-only layout update. TechBench Server 0.6.13
and the schema-version-15 SQL deployment remain current; no server or SQL
update is required.
