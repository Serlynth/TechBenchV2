# TechBench V2 0.6.6-beta.24

- Adds an editable SSL VPN Port field to Connection records.
- Displays SSL VPN port immediately beneath External IP in the Connection
  Quick Reference card.
- Recognizes existing custom field labels such as SSLVPN Port and VPN Port.

This is a Client Info Beta client-only data-display update. TechBench Server
0.6.13 and schema version 15 remain current; no server or SQL update is
required.
