# TechBench 0.5.29

This coordinated client and server release restores the active WHD organization administrator to the AD-user mapping roster.

- WHD technician synchronization now merges the authenticated `currentTech` resource with the normal `Techs` collection.
- Active administrator accounts such as `WHDmgr` / Helpdesk Manager remain available even when WHD omits the authenticated account from the collection response.
- Duplicate technician records are still removed, and genuinely inactive technicians remain hidden from mapping choices.
- No database change is required when upgrading from schema version 11.
