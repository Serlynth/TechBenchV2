# TechBench 1.1.0

- Links saved notes as related work or directional follow-ups.
- Suggests relevant notes from the same ticket, client, and recent work, with full-text search.
- Opens linked notes directly from the editor.
- Starts a clean continuation note while preserving its relationship to the original work.
- Preserves note relationships through delete undo and recovers unfinished continuation links after a restart.
