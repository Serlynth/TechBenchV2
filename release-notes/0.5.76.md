# TechBench 0.5.76

- Opens an inventory device directly in the Equipment Board editor when its card is clicked from Client Info or Client Users.
- Adds AnyDesk Number and AnyDesk Password fields for Desktop and Laptop equipment.
- Keeps AnyDesk passwords masked by default, available only to TechBench Admins, and encrypted in SQL Server.
- Keeps AnyDesk details off shared equipment cards and out of regular-user equipment reads.

This release requires TechBench database schema 15. Apply the included SQL Server update, then install TechBench Server 0.5.76 and update the clients.
