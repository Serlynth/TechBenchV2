# TechBench V2 0.5.116-beta.1

- Adds a **Client exports** section to Client Match.
- Generates a native Excel `.xlsx` audit workbook without requiring Microsoft
  Excel to be installed.
- Includes Summary, Matched, WHD Only, Sage Only, Manual/Other, and All Clients
  worksheets.
- Reports active/inactive totals plus the canonical TechBench name, WHD and
  Sage names/IDs, contacts, source state, match status, and last sync time.
- Keeps the export independent of the current Client Match search so the
  workbook always audits the complete client list.

This is a **client-only beta update**. No server, SQL, or sync-service update is
required.
