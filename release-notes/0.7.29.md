# TechBench 0.7.29

- Adds a dedicated FireDrill tab to newly generated Client Information migration workbooks.
- Uses the selected client's current FireDrill column labels in their existing order, including custom columns added later; when FireDrill is unavailable, the real legacy FireDrill columns are supplied as a fallback.
- Imports populated FireDrill cells as encrypted Client Information credentials and places them in the relevant Connection, Wi-Fi, Applications, Domains & Email, Backup, Security, Servers, or Needs Sorting section without dropping unknown future fields.
- Keeps prior TB-CI-10 and older migration workbooks importable while advancing newly generated workbooks to TB-CI-11.

This is a Stable client-only release. TechBench Server 0.6.24 and database schema 15 remain current; no SQL or Server Manager update is required.
