# TechBench V2 0.7.8

## WHD note verification

- Reads the WHD `mobileNoteText` representation used by TicketNotes responses,
  while continuing to support the `noteText` representation used for writes.
- Prevents correctly updated WHD notes from remaining in **WHD sync pending**
  solely because WHD returned the note through its read-specific field.
- Requests fresh note data during read-back verification to avoid accepting a
  cached pre-update response.
- Keeps verification fail-closed: TechBench still will not report a note as
  synchronized when WHD omits the text or returns genuinely different content.

## Deployment

- This is a Stable client-only update. No TechBench Server or SQL update is
  required.
