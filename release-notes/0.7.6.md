# TechBench V2 0.7.6

## WHD image attachments

- Fixes WHD image uploads when `JSESSIONID` was issued during an earlier
  authentication request or an HTTP redirect and therefore was not repeated on
  the final attachment-session response.
- Uses WHD's documented `JSESSIONID` cookie and the current REST session key as
  `wosid` for TechNote attachment uploads; the temporary session key is never
  added to the upload URL.
- Replaces any retained `wosid` with the current temporary WHD session before
  uploading, removes it after cleanup, and prevents overlapping image uploads
  from mixing temporary sessions.
- Requires WHD to return a positive attachment ID, so a redirect to an HTML
  sign-in page cannot be mistaken for a successful upload.
- Continues to keep failed images selected for retry.
- Keeps cookie values out of errors and diagnostics.

## Deployment

- This is a Stable client-only update. No TechBench Server or SQL update is
  required.
