# TechBench 0.5.49

- Replaces the Client Credentials navigation item with a clickable **Client Info** parent that displays every synchronized workbook field.
- Adds **Client WiFi**, **Domain/AD**, **Connection**, and **Misc Info** child views with the same searchable client-and-detail workspace.
- Limits Client WiFi to Wireless-prefixed columns, Domain/AD to local domain and Active Directory fields, and Connection to WatchGuard fields.
- Uses Misc Info for every remaining field so child categories do not overlap or omit data.
- Adds a **Clear** button beside Search throughout the Client Info workspaces.
- No SQL schema update is required.
