# TechBench 0.5.17

## Reliable posting to slower Web Help Desk servers

- Workstation WHD requests now allow 90 seconds instead of timing out after 20 seconds, matching the server-side WHD integration.
- If a TechNote POST response is interrupted or times out after transmission begins, TechBench automatically searches the ticket for the exact note text and duration.
- When that read-back finds the saved TechNote, TechBench records its ID and marks the work entry WHD-posted.
- When the exact note cannot be verified, the attempt remains pending and unconfirmed so TechBench never performs a blind retry that could create a duplicate.

## Deployment

This release continues to use SQL schema version 8. No SQL migration or server-service update is required when upgrading from 0.5.16. Install the 0.5.17 client through its built-in updater or `TechBenchV2Setup.exe`.
