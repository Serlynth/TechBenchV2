# TechBench 0.5.12

## Credentials workbook header compatibility

- Corrects the sixth Credentials workbook header to the deployed spelling: `*if enabled -Firebox-DB\csri`.
- Continues to accept the former no-space spelling so an older workbook does not stop synchronizing after the update.
- Ignores case differences and repeated surrounding/inter-word whitespace while still validating all eleven columns in their required order.
- Keeps the existing SQL snapshot unchanged if any genuinely incorrect header or malformed row is encountered.

## Deployment

This release continues to use SQL schema version 8. No database migration is required when upgrading from 0.5.11, but the matching SQL artifact remains included for installation verification and clean deployments.

Run `TechBenchServerSetup.exe` as Administrator on the service host, then open **Credentials**, select **Sync now**, and confirm the health changes to **Completed** with a nonzero row count. Client workstations may update normally from the built-in updater.
