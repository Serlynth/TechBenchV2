# TechBench 1.2.14

- Makes the full Markdown internal-note editor a modeless companion so the main TechBench window remains usable while it is open.
- Keeps one live Markdown window tied to the active entry and updates its client context as the user moves between entries.
- Preserves TechBench's explicit save boundary: Markdown edits remain in the active editor until **Save Entry** or the main **Save** action is used.
- Keeps unsaved-change prompts and Sage-posted read-only locking in effect while the companion window is open.
- Opens historical Markdown notes in non-blocking, read-only windows for copying and reference.
