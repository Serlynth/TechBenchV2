# TechBench 0.5.38

- Client updates now delete downloaded full/delta packages and interrupted partial files after installation or on the next launch.
- The connection screen also performs cleanup, so first-time installations are cleaned even when the main workspace is not opened.
- Server Manager updates now delete verified ZIPs, checksums, extracted packages, and abandoned setup staging folders.
- Server Manager cleans leftovers from earlier releases on startup and reports the number of downloads removed and disk space reclaimed.
- Failed server downloads are removed immediately, while rollback and recovery folders remain protected.
