# TechBench V2 0.6.13

- Prevents the New Entry Client field from freezing while typing searches that
  contain spaces.
- Searches the synchronized client list locally after a short typing debounce
  instead of running a blocking SQL query for every keystroke.
- Keeps partial searches such as `a mont` working across client names and the
  existing WHD and Sage client fields.

This update does not change TechBench Server or the database.
