# TechBench 0.5.15

## Read-only Common Links launcher

- Common Links are now a read-only launcher for every user, including TechBench administrators.
- Add, Edit, Remove, and link-detail editing controls have been removed from the client.
- The launcher now uses the full workspace width.
- Group headings such as **Admin Portals** and **Hosted DNS** use a larger, brighter label with an accent bar for easier scanning.
- The Microsoft 365 Chrome Incognito preference remains available because it changes only how that link opens on the current workstation.

## Deployment

This release continues to use SQL schema version 8. No SQL migration or server-service update is required when upgrading from 0.5.14. Install the 0.5.15 client through its built-in updater or `TechBenchV2Setup.exe`.
