# TechBench 0.5.75

- Shows equipment assigned to a selected user inside the Client Users details drawer.
- Adds a client-wide inventory section to the full Client Info profile.
- Keeps equipment access read-only for regular TechBench users; equipment changes remain Admin-only.
- Continues opening Client Users and Client Info gracefully while the matching SQL update is being installed.

Install TechBench Server 0.5.75 and rerun the included SQL Server installer before using the new inventory views. The database schema remains version 14.
