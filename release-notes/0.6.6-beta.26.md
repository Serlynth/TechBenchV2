# TechBench V2 0.6.6-beta.26

- Adds an optional equipment link to each client attachment without moving or
  duplicating the stored file.
- Restricts equipment choices to active inventory assigned to the same client.
- Shows linked photos and documents beneath the selected device on the Client
  Information Equipment page and in the normal equipment details pane.
- Supports opening or copying a linked file directly from equipment details.
- Keeps attachment equipment changes protected by SQL row-version concurrency,
  role checks, and audit events.

This Client Info Beta update keeps TechBench Server 0.6.13 and database schema
version 15. It adds an idempotent schema-15 SQL extension for equipment links;
apply the included standalone SQL deployment before creating links. No separate
beta server-service package is required.
