# TechBench V2 0.6.6-beta.33

- Restores the original correctly sized New Entry client ComboBox and dropdown
  button.
- Moves arrow-key navigation into a dedicated ComboBox subclass so Up and Down
  are intercepted before WPF's built-in selection and close behavior runs.
- Enter confirms the highlighted client, while Escape closes the dropdown.

This Client Info Beta update does not change TechBench Server or the database.
