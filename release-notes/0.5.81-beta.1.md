# TechBench Inventory Beta 0.5.81-beta.1

- Leaves Inventory Notes blank when importing a PC configuration build sheet.
- Matches imported customer names more flexibly by ignoring punctuation,
  connectors, and legal suffixes.
- Selects a longer client name when the meaningful customer words provide a
  confident match, including `Marrone & O'Rourke` to
  `Teeters Harvey Marrone & O'Rourke LLP`.

This is a client-only beta update. It remains compatible with TechBench Server
0.5.80 and database schema 15.
