# TechBench V2 0.5.117-beta.1

- Adds **Imported from WHD** and **Imported from Sage** totals to the Client
  Match Excel Summary worksheet.
- Counts matched clients in both source totals so each number represents the
  complete population imported from that system.
- Retains the separate Matched, WHD-only, Sage-only, Manual/Other, and overall
  counts for reconciliation.
- Keeps the Summary focused on current active-client totals without separate
  inactive counts; inactive records remain available on the detailed tabs.

This is a **client-only beta update**. No server, SQL, or sync-service update is
required.
