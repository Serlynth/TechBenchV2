# TechBench V2 0.7.0-beta.1

## Beta-to-Stable migration bridge

- Delivers the graduated 0.7.0 Client Information feature set to installations currently following the Client Info Beta feed.
- Retires the saved Client Info Beta preference on first launch and changes future update checks to the Stable channel.
- After the bridge restarts, use **Check for Updates** to install the final Stable 0.7.0 release.
- No uninstall, reinstall, or database migration is required beyond the current TechBench Server 0.6.13 and schema-15 SQL deployment.
