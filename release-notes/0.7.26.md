# TechBench 0.7.26

- Allows an identical workbook to be imported again after its earlier review was discarded, superseded, or failed.
- Keeps closed import batches as SQL audit history without attempting to stage new rows into them.

This release is paired with TechBench Server 0.6.22. Apply the stable 0.6.22 SQL update once on the shared TechBench server before reimporting a closed workbook review.
