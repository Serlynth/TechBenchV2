# TechBench 1.2.13

- Adds CommonMark and GitHub-style Markdown support to Internal Note, including headings, emphasis, lists, task lists, block quotes, code, tables, links, and horizontal rules.
- Adds a large Source, Split, and Preview editor with live preview and `F11` full-screen mode.
- Preserves the exact Markdown source in the local entry and keeps the existing Save action as the database commit boundary.
- Renders historical internal notes as selectable and copyable Markdown.
- Keeps Sage-posted entries read-only in both the compact and full Markdown views.
- Treats raw HTML as visible text and allows clickable links only for HTTP, HTTPS, and email addresses.
- Leaves Work Note and all WHD/Sage posting behavior unchanged.
