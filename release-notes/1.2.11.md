# TechBench 1.2.11

- Adds **Use another WHD ticket** for posting a work note to an authorized closed ticket or a ticket assigned to another technician.
- Checks the entered ticket with a read-only WHD lookup and confirms its subject, client, and status before posting.
- Uses the existing hidden-TechNote post and ID/readback verification without changing the ticket's assignment or status.
- Leaves the entry pending with a clear permission message when the signed-in WHD technician cannot access the ticket's tech group.
- Accepts either a plain ticket number or a pasted `WHD-` number and preserves alternate targets when continuing work from an existing note.
