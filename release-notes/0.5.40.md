# TechBench 0.5.40

- Server Manager's **Web Help Desk > User Mappings** page now has a **Sync WHD technicians** button that queues only the technician roster, monitors the request, and refreshes the mapping grid when it completes.
- SQL Server accepts a dedicated `Technicians` WHD request type without scheduling clients, statuses, groups, or tickets.
- WHD current-account recovery now honors the `instanceId` returned by the temporary session. This supports multi-instance WebObjects deployments where `/Techs/currentTech` must use the same instance and allows the configured active Admin account, such as `WHDMgr`, to be recovered even when `/Techs` omits it.
- Database schema remains version 12, but the matching 0.5.40 SQL deployment must be reapplied before using the new button.
