# TechBench 0.5.18

## User-owned Web Help Desk posting authentication

- Client-side WHD posting, testing, ticket lookup, note synchronization, and status changes now authenticate with the signed-in user's private WHD username and secret.
- The organization-wide authentication mode configured in TechBench Server Manager is used only by the server synchronization service and is no longer forced onto workstation users.
- Personal WHD authentication is auto-detected as username/password, username/application API key, or technician API key without exposing the secret outside the user's Windows Credential Manager profile.
- A regression test verifies that an organization-wide application-API-key setting cannot override a user's private posting authentication.

## Deployment

This release continues to use SQL schema version 8. No SQL migration or server-service update is required when upgrading from 0.5.17. Install the 0.5.18 client through its built-in updater or `TechBenchV2Setup.exe`.
