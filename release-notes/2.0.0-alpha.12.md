# TechBench V2 2.0.0-alpha.12

## Server Manager update discovery

- Fixes a Windows PowerShell 5.1 compatibility bug that wrapped GitHub's release list as one nested array and caused Server Manager to report that no published service package existed.
- Adds regression coverage that requires GitHub release results to be captured before they are enumerated.
- Preserves the alpha.11 Server Manager configuration, shortcut repair, notification-area behavior, client boundary, and schema-version-7 contracts.

## One-time alpha.9 bootstrap

- An installed alpha.9 Manager cannot discover alpha.12 because the defect is in its own updater. Download and extract the alpha.12 service ZIP once, close the old Manager from its window or notification-area menu, and run `TechBench-ServerManager.ps1` from the extracted package as Administrator.
- In the extracted alpha.12 Manager, select **Check for updates** and then **Download & Install**. It updates the service, repairs its installed launcher companions and Start Menu shortcut, and can discover later releases normally.

## Deployment notes

- Requires database schema version 7 and introduces no SQL migration.
- Existing SQL configuration, service identity, and machine-protected WHD/Sage credentials are preserved.
