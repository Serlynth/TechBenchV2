# TechBench V2 2.0.0-alpha.11

## Server-owned synchronization configuration

- Moves all organization-wide WHD synchronization settings into TechBench Server Manager: HTTPS endpoint, authentication mode, service username, automatic schedule, health, and manual sync.
- Moves the server Sage System DSN, organization-wide ODBC username, shared activity item ID, health, manual customer sync, and large-removal confirmation into Server Manager.
- Moves AD-user-to-WHD-technician mapping into Server Manager so the complete shared synchronization setup is maintained on the service host.
- Uses the elevated operator's Windows identity and requires TechBench Admin authorization for every read, save, mapping, and manual sync request.
- Saves related non-secret settings in one SQL transaction with existing rowversion conflict protection and audit-enabled stored procedures.

## Client boundary

- Removes organization-sync configuration, mapping, and manual sync actions from the TechBench client.
- Removes the obsolete hidden client commands and Admin status polling for those server operations, leaving a single operational control surface.
- Keeps each technician's personal WHD username/credential in their own Windows Credential Manager for posting work notes.
- Keeps workstation-specific Sage ODBC, employee, password, and desktop automation preferences in the client.
- Displays the shared WHD connection and Sage activity item ID read-only where they affect personal posting.

## Deployment notes

- Requires database schema version 7 and introduces no SQL migration.
- Existing SQL-owned WHD/Sage settings, mappings, schedules, sync state, and machine-protected secrets are preserved.
- Update both the service and client to alpha.11 so obsolete client-side organization controls are removed.
