# TechBench V2 0.6.6-beta.22

- Replaces the bright double-bar column resize controls in Client Info tables
  with clean, invisible hit targets.
- Shows a single subtle separator only while hovering over a resize boundary,
  then highlights it while dragging.
- Keeps every table column resizable without the persistent visual clutter.

This is a Client Info Beta client-only style update. TechBench Server 0.6.13
and schema version 15 remain current; no server or SQL update is required.
