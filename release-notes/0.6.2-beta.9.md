# TechBench V2 0.6.2-beta.9

This beta finishes the next Client Information category cleanup.

- **Wi-Fi** is now its own Client Information category and migration workbook
  tab for wireless networks, access points, SSIDs, and controllers.
- **Network appliances** and switches are assigned to **Servers &
  Infrastructure**, including records carrying older beta category prefixes.
- The Equipment description now focuses on computers, printers, and other
  end-user devices.
- The `TB-CI-5` workbook includes the new Wi-Fi tab and clearer category
  guidance. Earlier `TB-CI-4`, `TB-CI-3`, `TB-CI-2`, and `TB-CI-1` workbooks
  remain importable; Wi-Fi rows in an older Connection/Network tab are sorted
  into the new Wi-Fi category automatically.
- FireDrill behavior, stable TechBench behavior, and the SQL schema are
  unchanged. This is a client-only beta update and requires no SQL scripts.
