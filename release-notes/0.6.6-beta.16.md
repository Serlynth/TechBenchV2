# TechBench V2 0.6.6-beta.16

- Completes the Demo Client's network sample data with Status, Admin,
  Firebox-DB, AuthPoint, SSL VPN, WatchGuard Cloud, WatchGuard AD-auth, Wi-Fi
  administrator, staff SSID, and guest SSID credentials.
- Makes every fake Demo Client password available through the normal Reveal
  and Copy actions without touching SQL or recording a real credential audit.
- Keeps every requested Wi-Fi and Connection overview row visible. Missing
  real-client values now say `Not entered`, and an SSID without a linked
  password says `Password not entered` instead of silently hiding the gap.

This is a Client Info Beta client-only correction. TechBench Server 0.6.13 and
schema version 15 remain current; no server or SQL update is required.
