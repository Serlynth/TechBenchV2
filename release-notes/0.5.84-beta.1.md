# TechBench Inventory Beta 0.5.84-beta.1

- Adds Inventory as a clickable sidebar section immediately below Client Info.
- Shows a dedicated Stock Room overview containing only equipment currently in
  stock.
- Renames the existing drag-and-deployment workspace to Equipment Board and
  places it beneath Inventory as a subsection.
- Opens stock cards and client-assigned equipment directly in Equipment Board.

This is a client-only beta update. It remains compatible with TechBench Server
0.5.81 and database schema 15.
