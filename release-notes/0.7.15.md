# TechBench V2 0.7.15

## Connection and Internet

- Adds a separately selectable **Comcast Business Internet** circuit to Demo Client while preserving the existing WatchGuard firewall example.
- Gives Internet Circuit records a focused selected-record card with provider, account and circuit IDs, service speed, static addressing, support details, status, and linked account access instead of WatchGuard-only fields.
- Uses the same fictional reserved public address on the demo circuit and firewall so the example represents one consistent customer connection.

## Cleaner client information categories

- Removes **Admin Portal**, **Primary IP**, and **Support Contact** from Applications & Cloud forms, tables, and selected-record cards. Existing stored values are retained but no longer shown as stray custom columns.
- Moves **Barracuda Email Security** and the Spam Filtering type from Security to Domains & Email, with an email-security selected card and linked Barracuda access. Other Barracuda products, such as Backup or WAF, remain in their appropriate categories.
- Keeps the combined cloud-account quick reference for Barracuda, ESET, and Microsoft 365.

## Deployment

- This is a Stable client-only update. No TechBench Server or SQL update is required; server 0.6.16 and schema 15 remain current.
