# TechBench V2 0.6.3

This corrective stable release supersedes the 0.6.2 server and SQL package.

- Corrects the Equipment Board verification to recognize the existing
  `Deployed` technician lane alongside `Assigned` and `Deployment`.
- Allows the idempotent SQLCMD deployment to complete all remaining
  verification stages, including canonical Client Info verification.
- Keeps the single stable-only Server Manager and Sync Service line compatible
  with both Stable and Client Info Beta desktop clients.
- Retains the Stable desktop Client Info Beta channel selector introduced in
  0.6.2; Stable continues to open the original FireDrill pane.

If the 0.6.2 SQL bundle stopped with error 52220, back up the database and run
the complete 0.6.3 SQLCMD bundle over it. Already completed migrations are
recognized and preserved.
