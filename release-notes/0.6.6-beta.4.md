# TechBench V2 0.6.6-beta.4

- Adds an **Attachments** workspace to canonical Client Information for site
  photos, hardware pictures, diagrams, PDFs, and office documents.
- Supports multi-file selection, drag and drop, pasted screenshots or copied
  files, in-app image previews, normal Windows document opening, clipboard
  copy, and **Save copy**.
- Organizes new files automatically by immutable internal client ID under
  `Photos` and `Documents`; technicians do not need to manage folders.
- Adds editable category and caption metadata plus non-destructive
  archive/restore with concurrency protection.
- Keeps file data out of SQL. SQL stores only the relative path, original name,
  size, content type, SHA-256 hash, uploader, timestamps, and audit state.
- Preserves attachments through client display-name changes and duplicate-client
  merges.

This client requires the TechBench Server 0.6.13 SQL extension. Install the
stable 0.6.13 server package, apply its standalone SQL file in SSMS with SQLCMD
Mode enabled, and configure the UNC storage root under **Server Manager >
Attachments** before uploading. The additive database extension remains schema
version 15, so existing stable clients remain compatible.
