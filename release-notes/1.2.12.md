# TechBench 1.2.12

- Keeps WHD-posted entries editable until Sage is successfully posted.
- Saves changes back to the exact original WHD TechNote with an ID-based `PUT`; update failures never create a duplicate note.
- Adds three-way note reconciliation using the local note, current WHD text, and last verified snapshot. One-sided changes sync automatically and competing changes require confirmation.
- Adds **Sync WHD Note** to pull and verify the current WHD note on demand.
- Requires a ticketed entry's exact WHD note to be synchronized before Sage automation starts.
- Makes a verified Sage post the permanent lock boundary, removes the old edit bypass, and enforces immutability in the repository.
- Preserves exact WHD tracking by preventing deletion of entries already synchronized to WHD.
