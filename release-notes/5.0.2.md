# TechBench 5.0.2

Version 5.0.2 reorganizes TechBench Server Manager so related controls stay together and normal administration no longer depends on scrolling through one long mixed column.

- The main Manager area now has full-width `Service`, `SQL Server`, `Web Help Desk`, `Sage 50`, and `Updates` tabs.
- Windows service status and identity controls are grouped on the Service tab.
- SQL connection settings have their own tab.
- WHD and Sage protected credentials now live with their corresponding integration settings.
- Web Help Desk contains separate `Connection & Sync` and `User Mappings` sections, allowing the mapping table to use the available window space.
- The activity panel remains visible along the bottom and shows its newest messages first.

The database remains schema version 7 and this release does not add a database migration.
