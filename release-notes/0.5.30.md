# TechBench 0.5.30

- Admin Center now supports selecting multiple active TechBench clients and sending one update alert or sign-out request to all selected sessions.
- Every multi-recipient action opens a live response window that refreshes every two seconds and shows each recipient as waiting, acknowledged, dismissed, signed out, or save-failed.
- Forced sign-out now presents both a Windows notification and an in-app confirmation on the affected workstation before TechBench closes.
- Forced sign-out still waits for any active posting operation and saves current work as a recovery draft without posting it to WHD or Sage.
- This release continues to use SQL Server schema version 11; no SQL update is required when upgrading from 0.5.24 through 0.5.29.
