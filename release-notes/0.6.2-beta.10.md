# TechBench V2 0.6.2-beta.10

This beta adds category-specific columns and controlled custom fields to Client
Information.

- Servers & Infrastructure now captures Primary IP, Management IP, and
  Additional IPs / Subnet.
- Connection & Internet now captures Public / WAN IP, Gateway, Subnet / CIDR,
  and Circuit ID.
- Wi-Fi now captures Management IP, SSID, VLAN, and wireless security.
- Applications & Cloud now captures Tenant / Instance, Hosting Type, and an
  optional Primary IP.
- Each category grid displays its relevant standard columns. Custom resource
  fields automatically become additional columns and can be added, edited, or
  deleted through the **Custom Fields** button.
- The `TB-CI-6` migration workbook includes the standard category columns and
  imports optional headings beginning with `Custom:` into canonical resource
  fields. `TB-CI-5` through `TB-CI-1` remain importable.
- Resource-field saves and deletes use stored procedures, row-version conflict
  protection, least-privilege grants, and audit events.
- This beta requires the updated schema-15-compatible SQL deployment to refresh
  Client Info procedures and permissions. Stable TechBench and FireDrill remain
  compatible with the same database.
