# TechBench 0.5.24

## Admin communication and safe sign-out

- Admin Center notices now prompt the recipient for a written response and keep recent responses visible to TechBench Admins.
- Dismissing a notice records that it was seen even when no written response is supplied.
- A forced TechBench sign-out saves the complete current editor state to the user's SQL recovery draft without posting anything to Web Help Desk or Sage.
- If the recovery draft cannot be saved, forced sign-out is canceled and the client stays open so work is not lost.
- The sign-out result shown to Admins states whether a recovery draft was saved or no unsaved entry was present.

This coordinated release requires SQL schema version 11. Apply the 0.5.24 SQL installer before updating the server package and clients.
