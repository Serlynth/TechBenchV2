# TechBench 0.7.39

- Fixes the Client Information Users summary card failing to render after selecting a user because read-only Microsoft 365 display fields were activated as two-way WPF bindings.
- Selects the first user when the Users page opens and binds the summary card directly to the highlighted grid row, so the visible card no longer depends on a second selection state.
- Keeps assigned Inventory device cards synchronized with the selected user.

This is a client-only Stable update and remains compatible with TechBench Server 0.6.28.
