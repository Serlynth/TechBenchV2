# TechBench V2 0.6.2-beta.6

This beta removes an unnecessary approval blocker from the new migration
workbook introduced in beta.5.

- The client identity written into **Start Here** by TechBench now begins as
  verified.
- Users only need to review the rows they copy into Locations, People, Systems
  & Services, Equipment, Passwords, and Other Info.
- The separate **Workbook Imports** and **Client Information** workspaces,
  friendly `TB-CI-2` workbook, and compatibility with earlier `TB-CI-1`
  workbooks are unchanged.
- FireDrill remains available and unchanged during migration.

This is a client-only workflow update. It uses the existing schema 15 and does
not require another SQL update. Stable TechBench continues to work with the
same database.
