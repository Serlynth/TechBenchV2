# TechBench 0.7.34

- Corrects the Client Information lifecycle so matching WHD and Sage records creates one TechBench client in **Needs review**, rather than incorrectly presenting it as Live.
- Makes the Client Match workflow explain that the matched client becomes Live only after its workbook is reviewed and promoted.
- Keeps explicit **+ New client** creation as the immediate Live path for manually maintained clients.
- Preserves canonical TechBench IDs, tickets, notes, source links, and existing Client Information data while lifecycle state is corrected.

This Stable client release is paired with TechBench Server 0.6.28, which applies the lifecycle correction to SQL and safely repairs clients incorrectly marked Live by Server 0.6.26 or 0.6.27.
