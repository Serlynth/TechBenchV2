# TechBench V2 0.6.6-beta.13

- Adds an in-place note editor beside the This Week and History lists so an
  entry can be edited without leaving the current screen or losing the active
  date range and history filters.
- Keeps the selected saved entry and its WHD ticket loaded after Save, making
  the Post actions immediately available without reselecting the ticket.
- Includes the common note, date, time, billing, tags, follow-up, personal-note,
  WHD, and posting controls in the list-side editor, with a Full editor shortcut
  for less common fields.
- Keeps clicking another note on the same list available for rapid consecutive
  edits.

This is a Client Info Beta client-only update. TechBench Server 0.6.13 and
schema version 15 remain current; no server or SQL update is required.
