# TechBench V2 0.7.5

## Exact WHD note lifecycle

- Editing a TechBench entry that was already posted to WHD updates the exact
  tracked TechNote instead of creating a replacement note.
- Makes update verification resilient to WHD's HTML entities, paragraph tags,
  line-break formatting, and delayed read-after-write results.
- Adds coordinated deletion of the exact tracked WHD TechNote. TechBench first
  deletes and verifies the WHD note, then removes the local entry.
- Keeps the TechBench entry whenever WHD deletion fails or its result cannot be
  verified. An unsupported or ambiguous HTTP 404 is not treated as proof that
  the note was deleted.
- Permanently prevents deletion after an entry is posted to Sage. Neither the
  TechBench entry nor its WHD TechNote is deleted, including during concurrent
  WHD/Sage activity.
- Keeps local Undo available after coordinated deletion without incorrectly
  marking the restored entry as still posted to the deleted WHD TechNote.

## Deployment

- This is a Stable client-only update. No TechBench Server or SQL update is
  required.
