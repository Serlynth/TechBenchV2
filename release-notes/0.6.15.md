# TechBench Server 0.6.15

- Fixes the schema-15 Client Attachments upgrade failing with `Invalid column
  name 'EquipmentId'` on databases that already had the attachment table.
- Defers creation of the equipment foreign key and filtered index until after
  the additive `EquipmentId` column exists.
- The failed `0.6.14` attachment upgrade was transactional, so the corrected
  standalone SQL deployment can be safely rerun without manual cleanup.
- Includes the corrected standalone SQL deployment, Sync Service package,
  Server Manager, and one-click server installer.
