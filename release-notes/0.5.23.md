# TechBench 0.5.23

- Adds an Admin-only **Admin Center** to the normal TechBench client.
- Lets an Admin queue an immediate organization-wide WHD ticket synchronization or manual Sage customer synchronization; the existing server Sync Service still performs all external-system work.
- Shows TechBench clients active within the last 90 seconds, including user, computer, client version, current section, unsaved-work state, busy state, and last heartbeat.
- Lets an Admin send a visible update notice to a selected active client.
- Lets an Admin require a selected client to close TechBench safely. The client waits for an active posting operation, preserves unsaved entry work as a recovery draft, acknowledges the request, and closes only TechBench.
- Keeps read-only user previews outside the presence system and enforces all Admin/session ownership boundaries in SQL stored procedures.

This coordinated release requires SQL schema version 10. Apply the 0.5.23 SQL installer and update the server package and clients together.
