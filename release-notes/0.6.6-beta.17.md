# TechBench V2 0.6.6-beta.17

- Replaces the separate password-reveal dialog with an inline Reveal / Hide
  control in Client Info quick-reference cards and the full Passwords section.
- Keeps Copy beside the value as a one-click action without navigating away or
  opening another window.
- Clears revealed values when they are hidden, when Client Info is refreshed,
  or when the Client Info window closes. Real credential reveal and clipboard
  access continue to use the existing audit path.

This is a Client Info Beta client-only usability update. TechBench Server
0.6.13 and schema version 15 remain current; no server or SQL update is
required.
