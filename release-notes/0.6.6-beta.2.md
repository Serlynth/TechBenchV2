# TechBench V2 0.6.6-beta.2

- Moves WatchGuard AuthPoint from a separate push for each credential Reveal or Copy to one server-enforced push when the Client Info beta opens.
- Keeps the approved login in memory for that running client and validates its Windows SID, client instance, random token, expiration, and revocation in SQL before protected credential access.
- Adds global-all-users and per-user **Require at login** controls to the shared Server Manager for staged rollout.
- Keeps Windows Integrated Authentication as the first factor and automatically uses each authorized user's Active Directory email as the AuthPoint identity.
- Includes the Stable 0.6.5 window/workspace persistence improvements and leaves Stable, FireDrill, WHD, and Sage behavior unchanged on the shared schema-version-15 database.

Deployment requires the additive SQL Server 0.6.9 package and shared TechBench Server 0.6.9 before this beta is used. The SQL script must be run even if schema version 15 is already installed. See `README-AUTHPOINT-MFA.md` in the server package.
