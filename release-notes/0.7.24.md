# TechBench 0.7.24

- Fixes Client Information workbook staging when the workbook contains standard or custom resource fields.
- Updates the migration workbook so amber headers clearly identify the fields required on each populated row.
- Adds Excel dropdowns for review states, yes/no fields, Microsoft 365 licenses, resource types, static-IP assignment, location/contact/device types, and secret types.
- Keeps custom static-IP assignment text available while still offering the normal Dynamic, Single static, and Static block choices.

This release is paired with TechBench Server 0.6.17. Install the stable 0.6.17 server/SQL update once on the shared TechBench server before retrying a workbook that failed with `CK_ClientInfoRecords_Type`.
