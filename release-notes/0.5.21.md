# TechBench 0.5.21

- Reorganizes the client Settings workspace into compact preference/import and personal-posting columns, with Admin note templates kept in their own section.
- Removes the workstation Sage ODBC DSN, username, and password fields and deletes legacy client-side Sage ODBC settings when the user opens Settings.
- Keeps only each user's Sage employee ID and activity item ID in the client; shared Sage ODBC configuration and customer synchronization remain server-owned.
- Saves Sage time tickets through the signed-in user's Sage Desktop session and uses Sage's native save result instead of a second client-side ODBC connection.
- Keeps manual linking available for recovery of an already-saved Sage ticket while preventing unresolved prior attempts from silently creating duplicates.

This release requires SQL schema version 9 and does not change the schema from TechBench 0.5.20. If the database is already verified at version 9, no SQL deployment is required; update the client, and update Server Manager/Sync Service for coordinated version alignment.
