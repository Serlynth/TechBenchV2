# TechBench V2 0.6.6-beta.5

- Fixes note-editor recovery drafts failing with `ExpectedRowVersion is
  required for an existing editor draft` on workstations whose generated
  device GUID has a negative hash value.
- Tracks draft concurrency with the actual SQL row version instead of using a
  collision-prone numeric hash of the device GUID.
- Preserves optimistic concurrency: a genuinely changed draft is still
  rejected instead of being overwritten silently.
- Restores normal autosave status after an existing recovery draft is loaded
  and edited.

This is a Client Info Beta client-only hotfix. TechBench Server 0.6.13 and the
schema-version-15 SQL deployment remain current; no server or SQL update is
required.
