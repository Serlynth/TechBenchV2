# TechBench V2 0.6.6-beta.1

- Adds WatchGuard AuthPoint step-up authentication to canonical Client Info credential Reveal and Copy.
- Keeps Windows Integrated Authentication as the primary identity and validates one-time authorization in SQL Server, so direct stored-procedure calls cannot bypass MFA.
- Adds short-lived SID/action/secret-bound challenges, replay prevention, rate limits, denial/timeout handling, protected audit events, and a two-person emergency break-glass path.
- Adds the AuthPoint (Beta) configuration and user-mapping pages to the single shared Server Manager. WatchGuard API secrets remain LocalMachine DPAPI-protected on the server.
- Includes the Stable 0.6.5 window-size, maximize-state, last-module/page, update-foregrounding, and remembered-module branding improvements.
- Leaves Stable 0.6.5, FireDrill, WHD, and Sage behavior unchanged on the same schema-version-15 database.

Deployment requires the additive SQL Server 0.6.6 package and the shared TechBench Server 0.6.6 package before AuthPoint is enabled. See `README-AUTHPOINT-MFA.md` in the server package.
