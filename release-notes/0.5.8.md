# TechBench 0.5.8

- Removes the organization-specific Credentials workbook location from the SQL
  defaults, application source, and packaged documentation.
- Makes the workbook UNC path an explicit Admin-only Server Manager setting
  that can be changed whenever the workbook moves.
- Prevents ordinary clients and read-only Admin preview sessions from receiving
  the saved server path through the shared-settings procedure.
- Does not queue the daily import until a workbook path has been configured and
  gives Admins a clear error if they request a manual sync before configuring it.

Version 0.5.8 continues to use SQL schema version 8. Rerun the complete SQL
installer before updating the server and client packages.
