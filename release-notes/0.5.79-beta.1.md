# TechBench Inventory Beta 0.5.79-beta.1

- Renames the user-facing Equipment Board workspace to **Inventory**.
- Adds an **Import build sheet** action for Excel PC Configuration workbooks.
- Imports Customer, Machine, S/N, Machine Name, End User, and Email Address into a new device for review before saving.
- Matches the synchronized client and that client’s user when possible; unmatched source details are retained in Notes for review.
- Ignores Build Date, Delivery Date, component-availability, and machine-image fields.

This is a client-only update. It remains compatible with TechBench Server 0.5.76 and database schema 15.
