# TechBench V2 0.6.6-beta.20

- Removes Core Infrastructure, Backups, Vendors, and Veeam from the technician
  quick-reference area so it stays focused on frequently used connection and
  account information.
- Keeps all of those records and their complete summaries available in the
  existing detailed Client Info category tabs.
- Simplifies the Domain & AD quick-reference card to AD domain, email domain,
  and domain-administrator username/password only; URLs are no longer shown.

This is a Client Info Beta client-only layout update. TechBench Server 0.6.13
and schema version 15 remain current; no server or SQL update is required.
