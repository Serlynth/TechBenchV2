# TechBench 0.5.10

This release adds update recovery directly to the SQL connection screen. A
client that detects a newer database schema now checks the public TechBench
release channel automatically, presents the compatible client version, and can
download, install, restart, and reconnect without first opening the workspace.

The connection action remains disabled while the schema versions are
incompatible, and the full-width status area reports update discovery and
download progress clearly. A normal **Check for updates** action is also
available from the connection screen when SQL Server is unavailable.

Version 0.5.10 continues to use SQL schema version 8. Existing schema-8
deployments do not add another migration, but the coordinated SQL and server
artifacts are republished so all installation media remains version-matched.
