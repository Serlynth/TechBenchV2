# TechBench 0.5.22

- Repairs the 0.5.21 client update package so the x86 TechBench application always includes an x86-compatible `TechBench.WHD.dll`.
- Separates shared WHD build outputs by target architecture so x64 test/server builds cannot be reused by the x86 client publisher.
- Adds release-time validation that rejects a client package when the shared WHD assembly is missing or has the wrong processor architecture.
- Retains the reorganized client Settings page and server-owned Sage ODBC boundary introduced in 0.5.21.

This release requires SQL schema version 9 and does not change the database schema. No SQL deployment is required when the database is already at version 9.
