# TechBench 0.5.1

TechBench V2 now uses the intended `0.5.x` development release line. Future releases increment from `0.5.1` to `0.5.2`, `0.5.3`, and so on.

- Reorganizes Server Manager into dedicated Service, SQL Server, Web Help Desk, Sage 50, and Updates tabs.
- Separates WHD connection and synchronization controls from bulk AD-to-WHD technician mappings.
- Lists active WHD technicians only and supports mapping all TechBench Users and Admins in one grid.
- Keeps Server Manager activity newest-first so current status is visible without scrolling.
- Preserves service identity, SQL configuration, protected WHD/Sage secrets, and existing database data during the numbering transition.

Installations currently on `5.0.1` or `5.0.2` must first install the one-time `5.0.3` transition bridge, then check for updates again to install `0.5.1`.

No SQL schema update is required from the existing schema-version-7 deployment.
