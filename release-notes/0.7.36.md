# TechBench 0.7.36

- Adds a readable selected-user summary with a full, wrapping name and the user’s important contact, AD, Microsoft 365, Azure Sync, password, and PC details.
- Renames the user-facing “365 uses AD login” wording to **Azure Sync** in Client Information and new migration workbooks while retaining compatibility with existing workbooks.
- Makes the Passwords list horizontally readable with practical column widths, a frozen Name column, a resizable details pane, and remembered column/pane sizing.
- Imports FireDrill wireless management, SSID, and password fields into a linked Wi-Fi record instead of treating every value as a standalone password. Previously imported wireless values also appear on the Wi-Fi tab.
- Makes **Make Live** the explicit final workbook step and removes Review fields and columns after Client Information is live.

This is a client-only Stable update and remains compatible with TechBench Server 0.6.28.
