# TechBench V2 0.6.0

TechBench 0.6.0 promotes the completed Inventory Beta line to Stable and
establishes one unified client, server, and SQL baseline.

## Inventory and deployment

- Adds the searchable Inventory registry for importing, editing, filtering,
  copying, and managing every equipment record.
- Keeps Equipment Board focused on technician assignment, priority, drag/drop,
  deployment ordering, and deployment completion.
- Imports PC build sheets with automatic client and client-user matching while
  excluding build dates, delivery dates, component/image flags, notes, and
  site/room values.
- Adds the completed deployment lifecycle without requiring a beta-only client
  or server workflow.
- Adds AnyDesk launch support from equipment details with unattended-password
  handoff when a password is available.

## Client information

- Adds Client Users, Client WiFi, Domain/AD, Connection, Veeam, Miscellaneous,
  and complete client-profile workflows from the synchronized FireDrill
  workbook.
- Keeps equipment details on the current screen and closes equipment panes
  cleanly when navigating.
- Makes the canonical TechBench client name editable while preserving WHD and
  Sage identities and suggesting the current matched source name.
- Adds native Excel client-match audit exports with current WHD-imported,
  Sage-imported, matched, WHD-only, Sage-only, Manual/Other, and complete
  client views.

## Workspace and synchronization

- Adds the private SalesBench and AdminBench shells and moves administrative
  tools into AdminBench.
- Improves WHD and Sage client matching, canonical profile resolution, Windows
  SID reconciliation, cursor-based ticket synchronization, timeout handling,
  and malformed WHD-client tolerance.
- Includes the combined FireDrill, equipment, AnyDesk, and deployment database
  capabilities through schema 15.

## Unified release channel

- Retires the active Inventory Beta selector now that every completed beta
  feature is in Stable.
- Migrates saved beta-channel preferences to the Stable update feed.
- Publishes matching 0.6.0 client, Server Manager, sync service, Sage worker,
  server setup, and SQL deployment assets.
