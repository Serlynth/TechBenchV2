# TechBench Inventory Beta 0.5.89-beta.1

- Reorganizes the sidebar into collapsible Worklog, Service, Clients,
  Equipment, and System groups so future workspaces have a predictable home.
- Moves the application navigation and header into shared controls, replacing
  page-specific active-state styles with one reusable navigation pattern.
- Adds dark, compact scrollbars across the application and keeps the workspace
  status visible while long navigation groups scroll independently.
- Tightens Equipment Board lanes and simplifies equipment cards around name,
  identity, status, asset tag, location, and deployment owner so more work fits
  on screen without losing the important context.
- Adds a database-free `--shell-demo` mode for visual QA of the application
  shell without authenticating, connecting to SQL, or saving business data.
- Adds regression coverage for the shared navigation, header, active-state
  converter, demo startup path, and app-wide scrollbar styling.

This is a client-only beta update. It remains compatible with TechBench Server
0.5.81 and database schema 15.
