# TechBench Inventory Beta 0.5.94-beta.1

- Makes Equipment Board and popped-out client-profile details use one shared
  equipment information layout.
- Standardizes field names and order across read-only details and the editable
  Inventory sheet.
- Keeps empty fields visible with a dash so the layout no longer changes from
  one equipment record to another.
- Shows the same equipment, remote-access, assignment, notes, and assignment
  history sections in every read-only view.
- Keeps AnyDesk passwords protected outside the Admin equipment view.
- Removes the retired hidden equipment editor and duplicate details markup so
  future fields only need to be added once.

This is a client-only beta update. It remains compatible with TechBench Server
0.5.81 and database schema 15.
