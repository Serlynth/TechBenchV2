# TechBench Inventory Beta 0.5.91-beta.1

- Opens equipment selected from a popped-out client overview inside that same
  client profile instead of closing the profile and redirecting the main
  workspace to Inventory.
- Adds a read-only client equipment drawer with device, assignment, remote
  access number, location, technician, status, and notes context.
- Keeps the complete client overview visible behind the drawer.
- Makes Escape close equipment details first; a second Escape closes the client
  profile.
- Adds regression coverage for the in-profile selection and close behavior.

This is a client-only beta update. It remains compatible with TechBench Server
0.5.81 and database schema 15.
