# TechBench 0.5.27

This coordinated client, server, and SQL release fixes an Admin Center crash caused by rendering the first client response.

- Recent client responses now bind every computed display label one-way, including the user label rendered inside a WPF `Run`.
- An acknowledged update notice or written reply can refresh into Admin Center without terminating the Admin's TechBench client.
- The protection also applies during startup, when an Admin has recent responses waiting to be displayed.
- No database change is required when upgrading from schema version 11.
