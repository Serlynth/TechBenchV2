# TechBench Inventory Beta 0.5.62-beta.1

- Adds an **Open Demo Mode** button to the live Inventory Board.
- Opens a complete sample inventory board with drag-and-drop assignments, priority ordering, deployment lanes, and sample device editing.
- Keeps demo data fully isolated on the workstation. Demo changes are never written to the shared TechBench SQL database.
- Closing Demo Mode returns to the unchanged live Inventory Board.
