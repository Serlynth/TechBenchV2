# TechBench Inventory Beta 0.5.85-beta.1

- Opens device details in a slide-out tray over the page you are currently
  viewing.
- Keeps Inventory, Client Users, and client profile views in place when a
  device is selected.
- Adds an explicit Open Equipment Board button when you want the full editable
  equipment workspace.
- Keeps AnyDesk passwords masked in the quick-view tray unless Show password is
  selected.

This is a client-only beta update. It remains compatible with TechBench Server
0.5.81 and database schema 15.
