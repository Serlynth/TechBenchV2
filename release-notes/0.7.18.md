# TechBench 0.7.18

- Adds a downloadable, current-format TechBench Inventory build sheet directly beside the Inventory import action.
- Imports device type, manufacturer, model, part number, serial number, asset tag, IP address, and AnyDesk details in addition to client, user, email, and machine name.
- Keeps older PC Configuration Sheet workbooks compatible and continues to leave Notes and Location blank while ignoring build/delivery dates and component/image flags.
