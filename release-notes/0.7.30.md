# TechBench 0.7.30

- Replaces the confusing Hypercare cutover label with a simple Live status as soon as Client Information is promoted.
- Removes cutover jargon from the Client Information list and live client header while preserving useful pre-import statuses such as Not Started and Staging.
- Keeps existing databases compatible: clients whose stored legacy state is Hypercare display as Live immediately, with no SQL or Server Manager update required.
- Aligns future full SQL deployments so promoted imports finish in the Complete state instead of starting an unused five-day Hypercare stage.

This is a Stable client-only release. TechBench Server 0.6.24 and database schema 15 remain current; no SQL or Server Manager update is required.
