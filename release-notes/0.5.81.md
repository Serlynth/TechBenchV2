# TechBench 0.5.81

- Corrects the Inventory encryption update for installations whose TechBench
  permissions are inherited through Active Directory groups.
- Keeps caller authorization in the public Inventory procedures and delegates
  only AnyDesk encryption/decryption to private owner-executed helpers.
- Restores normal Windows-group role detection after applying the matching SQL
  deployment.
- Makes equipment saves transactional so an encryption failure cannot leave a
  partial Inventory record.

Apply the matching 0.5.81 SQL deployment even if the database already reports
schema version 15.
