# TechBench V2 0.7.0

## Stable graduation

- Graduates the complete Client Information workspace and workbook-import workflow from Beta into Stable.
- Includes category-aware Client Information records, selected-record quick reference cards, editable and copyable secrets, client attachments linked to equipment, the populated Demo Client, and remembered profile layouts.
- Includes the AuthPoint login enforcement used to protect Client Information secrets when it is enabled by the server administrator.
- Preserves the existing FireDrill, Equipment Board, Inventory, time-entry, WHD, Sage, and stable workflow improvements through the previous releases.

## Update-channel migration

- Retires the Client Info Beta update option. Existing Stable installations update directly to 0.7.0.
- Existing Beta installations first receive the 0.7.0-beta.1 migration bridge. On launch, that bridge changes future update checks to Stable so 0.7.0 can be installed normally.
- Stable and former-Beta installations continue to use the same TechBench application identity; no uninstall or manual data migration is required.

## Server compatibility

- Use the current TechBench Server 0.6.13 package and schema-15 SQL deployment for Client Information, attachments, and optional AuthPoint enforcement.
- The database remains shared with FireDrill and the existing TechBench services.
