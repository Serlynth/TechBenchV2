# TechBench 0.5.5

- Restores safe many-location-to-one-customer matching from V1 for numbered WHD location families.
- Automatically groups records such as `People for People 700` and `People for People 800` under the unique Sage customer `People for People Charter School`.
- Keeps semantic multi-location ambiguities, such as restaurant versus speak-easy locations, available for Admin review instead of guessing.
- Adds a narrow service-only SQL merge operation that preserves every WHD external identity and moves related tickets, work entries, and aliases into the shared customer atomically.

This release adds no database migration and remains at schema version 7. Reapply the included SQL Server deployment before updating the server components.
