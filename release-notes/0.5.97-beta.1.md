# TechBench Inventory Beta 0.5.97-beta.1

- Adds **Connect with AnyDesk** to the editable Inventory pane, the
  Equipment Board/current-page details pane, and the full client-profile
  equipment pane.
- Launches the locally installed AnyDesk client with the stored 9- or 10-digit
  ID or AnyDesk Alias and immediately requests the remote session.
- Submits the stored unattended-access password through AnyDesk's standard
  input support. The password is never placed in command-line arguments,
  copied to the clipboard, or written to TechBench status messages.
- Opens the normal AnyDesk connection prompt when an address is present but no
  unattended-access password is stored.
- Reports invalid addresses and missing AnyDesk installations clearly.
- Keeps manual **Sync all** comprehensive across every WHD reference category,
  while resuming Tickets from the last successful cursor instead of repeatedly
  scanning the complete historical ticket database.
- Preserves the required historical Tickets bootstrap when no successful
  cursor exists yet.
- Shows an active WHD job as **Synchronization is in progress** and labels a
  stored error as **Previous failure**, instead of presenting the old failure
  as the result of the running job.
- Includes all beta client changes through 0.5.96-beta.1, including the other
  task's unified equipment panes and Web Help Desk reliability updates.

No SQL deployment is required; database schema remains version 15. This release
includes a matching `TechBenchServerSetup.exe` to install the WHD cursor and
status changes on the Sync Service host.
