# TechBench V2 2.0.0-alpha.3

This candidate tightens the server-storage boundary so data intended for the whole team is genuinely organization-wide rather than merely stored on SQL Server under one user.

## Changes

- Makes custom Common Links organization-wide and administrator-managed.
- Adds a canonical shared tag catalog populated from work-entry tags, so every workstation receives the same tag suggestions.
- Makes CSV/import customer aliases shared matching knowledge while protecting existing mappings from non-admin reassignment.
- Makes newly managed note templates organization-wide and administrator-managed while retaining read compatibility for older personal templates.
- Splits shared connection defaults from per-user and per-workstation settings: WHD URL/authentication mode and the Sage activity item are organization settings; usernames and employee IDs remain per-user; DSN/company path, display, update, and refresh behavior remain local.
- Activates the workstation refresh interval so shared clients, tickets, statuses, matching, links, tags, and templates update without restarting the client.
- Adds schema-version-3 migration and verification for shared reference data.

## Deployment note

This client requires the matching SQL Server 2016 schema-version-3 deployment. Back up `TechBench`, rerun the complete standalone SQLCMD deployment, and install alpha.3 as one coordinated test cutover. Existing V1 SQLite data is not migrated automatically.
